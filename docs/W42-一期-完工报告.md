## 做了什么

| 哪一块 | 在哪 | 做了什么 |
|---|---|---|
| 共用格式 | `packages/contract/src/d1max_contract/binding.py` | 绑定码（16 位 Crockford Base32，机器人只存哈希）、贴纸二维码 `D1MAXBOT1.`（可选配网地址 `a`）、6 位核对码、解绑令 `D1MAXUNBIND1.`（Ed25519，一台一张、最长 7 天）、WiFi 名和密码的规矩、遥测里 WiFi 状态的形状 |

| 清机（恢复出厂） | `bind/wipe.py` | 停服务；删数据根、外挂发件箱、站点证书私钥、注册文件、证据公钥；env 站点那几行回出厂值；清系统日志；路由器忘 WiFi；`fstrim`。留系统、程序、`device.json`、配网证书、解绑公钥、发行公钥、硬件标定和设备配置 |
| 代理 | `d1max_agent/bindlink.py`、`runtime.py` | 遥测带 `net.wifi`；`unbind`、`wifi_confirm` 两条命令转给配网服务 |
| 出厂工具 | `bind/factory.py`、`bind/cli.py`、`tools/sticker_label.py` | `factory burn / check / rekey`、`unbind-token keygen / sign`；贴纸 SVG 在生产线电脑上出 |
| 网页值班台 | `web/console/src/robotspage.tsx` | 「等待批准加入」（核对码、再输密码批准、能起名、拒绝）；卡片标「换 WiFi 等确认」、详情里确认 / 不换；解绑确认写明恢复出厂；「添加」说明用手机扫贴纸，开通码收到按钮后面 |
| 手机 App | `mobile/lib/net/robot_bind.dart`、`ui/robot_bind_page.dart`、Android `RobotHotspot.kt` | 添加向导（扫 / 粘贴贴纸 → 庄园 WiFi → 连热点 → 发给机器人 → 核对码 → 离开热点 → 管理员当场批准）；换 WiFi；工程师用解绑令解绑（站点列表页进）；列表顶上「等待批准加入」；详情显示 WiFi、确认换 WiFi |
| 演示站点 | `tools/site_demo.py --unbound N` | 起出厂状态的机器人（配网服务 + 假路由器），打印贴纸码；批准后起它的代理，解绑后收掉 |

## 实现时定的（设计里没写到的）

- 3588 的配网地址缺省 `192.168.1.2:8450`（烧写时写进 `D1MAX_BIND_HOST`），贴纸可以带别的（`a`）。
- 热点密码所有机器人统一一个（用户 10-30），所以手输序列号 + 绑定码就能连热点（热点名从序列号算）；手输的核不了机器人证书，不另外提示（用户 10-30）。桌面版可以粘贴整串贴纸码。
- WiFi 名由机器人的路由器扫出来、列表里选，密码手填；隐藏的 WiFi 手输名字（用户 10-30）。
- 摄像头扫码配网（手机亮码给机器人前摄像头、语音反馈）记下，后期做，先用热点（用户 10-30）。
- 连热点：Android 10 起用系统的「指定网络」，只要 `CHANGE_NETWORK_STATE`，不要定位权限（没用 wifi_iot 插件，它要定位、改系统设置）；iOS 这一期没做自动连，App 把热点名、密码摆出来教人去系统设置里连（iOS 自动连要在苹果开发者后台开「热点配置」权限）。
- 画二维码的库（segno）不装到机器人上，生产线电脑上出图。
