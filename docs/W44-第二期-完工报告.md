## 这一期做了什么

「管理」左边一列分三组：**常用**（家里的状况、布防时间、授权和访客、用户、机器人、报表）、**布置**、**高级**（默认收起来）。
布置、高级两组先挂现有页面，第三、四期重做。工程师（临时）账号看得到「管理」，看不到「用户」。

**网页**

- **家里的状况**（换掉第一期的「提醒」）：要你处理的事（技术提醒说人话、写该做什么、按钮去哪；没有整块不显示）；今天的安排（各防区几点布防、今天的授权、访客到几点、切模式、现在谁说了算）；机器人小卡片；这周比上周。
- **布防时间**：一周七行 0–24 点，拖出色块、点了删、拖两边改（吸到 30 分钟）、复制到别的天；全部防区一样 / 每个防区单独设；例外；交班时间、多久没巡过；一个保存；没存离开会提醒；写明现在谁说了算。
- **授权和访客**：现在生效的在上面、能提前结束；加授权（每周重复，或只这一天）；全部授权；访客模式单独一块（选防区、1–24 小时、现在结束）。
- **用户**：表（名字、界面角色名、最后登录、状态）；给工程师开临时账号（再输密码、口令只显示一次）；工程师那行写还剩多久；删人要确认；点人看他做过什么（动作说人话）。
- **机器人**：卡片（名字、在线、电量、今天几趟、毛病）；详情（改名、版本、证书、最近的毛病、手动 / 自动派、重出开通码、解绑要确认 + 再输密码）；添加（现有登记码流程，写明以后改扫码）。起的名字保安页（值班、实况、地图、录像）也用。
- **报表**：这周 / 上周 / 这个月 / 自己选（最长 31 天）；四个大数字；按天柱状图；事件点了看录像；导出 PDF = 浏览器打印，导出表格 = CSV。
- 顶栏：时间表管着时写「按时间表：布防 / 部分布防 / 撤防」。
- 手机：时间表管着时模式那一行写「按时间表：……」、「按时间表切的」。

## 我替用户定的（Rulings）

1. 报表汇总用「能看」的权限（跟现有日报一样），保安也能看到汇总数。
2. 授权的「今天有没有」、提前结束沿用授权本来的钟（站点主机本地时间），没换成站点时区 —— 跟「现在生效」同一个钟；站点主机时区跟路线库时区不一样时，授权会差几个小时（B1c 起就这样，另立）。
3. 「只这一天」的授权，星期几由网页按选的日子算。
4. 机器人概览多回一项「只能手动派」（详情页要用）。
5. 报表的这周 / 上周 / 这个月从几号到几号由网页按浏览器时间算；每天的数由站点按站点时区数。
6. 旧机器人页「在线」的三条网页测试、旧值班日报「只导出现在选的那一份」的测试随旧页删了；新页沿用同样的规矩，在线由站点算（Python 测试管着）。
7. 工程师账号在手机 App 上暂时什么都不能操作（手机只认业主、保安、家人），第四期地图重建要用手机遥控时再接。
8. 摄像头登记暂挂在「高级 → 系统」页底下，第三期挪进「布置」。
9. 电池健康这一期不显示（机器人还不报）；照片位放图标。
10. 「家里的状况」打开时拉一次（技术提醒是实时的）。
