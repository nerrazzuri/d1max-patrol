**站点后端**

| 新东西 | 做什么 |
|---|---|
| 告警分给谁 `alert_audience.py` | 71 种告警逐个写明：有人闯入 / 起火过热（热像实物到了才有）/ 机器人需要帮忙 / 掉线给保安，技术类给业主；没写的兜底给业主。回包多 `audience` |
| 报警结论 | 解决告警时带 `verdict`：intruder 确认有人 / false_alarm 误报 / handled 处理好了（不带照旧能用）；落库（库结构 61 `alerts.verdict`） |
| 交班留言 `/api/shift-notes` | 看最近一条、写一条（作者取登录账号，1–500 字，进审计） |
| 位置轨迹 `pose_track.py` | 按遥测的 stamp（机器人的钟，跟录像同一个钟）记，挪 1 米或过 10 秒记一个，留 30 天；`/api/robots/{id}/track`（最多 24 小时）、`/api/coverage`（每 2 米一格最后一次有人去过） |
| 最近的机器人 `/api/robots/nearest` | 按跟机器人同一份的规划算路程挑最近的（同一张图同一版、在线、新鲜、没被接管、不在驱离），回谁、几米、约几秒 |
| 保安的临时路线 | `POST /api/robots/{id}/patrol` 多收 `points`（1–20 个）：校验跟存路线同一套，走一趟、不进路线库，审计写 `temp` |
| 授权此刻生效 | 授权列表每条带 `active_now`（星期、跨午夜、时区只在站点算） |
| 录像抓一帧 `/api/recordings/frame` | ffmpeg 从那一刻所在的段取一帧、缩到 320 宽出 JPEG，按（段、整秒）缓存 256 张；报警记录的抓拍用 |

库结构 60 → 61（加 `alerts.verdict` 列、`shift_notes`、`pose_track` 两张表），带第 60 版快照。告警回包形状变了，手机夹具按规矩重生成。

**网页**（设计 §4）

- **外壳和顶栏**：品牌和站点名、五个保安页 + 业主的「管理」、给保安的报警数、布防状态（只显示）、时钟、用户菜单（语言、外观、改自己的密码、退出）、全部急停。保安页深色、管理页浅色（个人可在「外观」里改）。角色的界面名字：业主（最高权限）/ 保安 / 家人。旧的视频墙、底部报警队列删掉；定位、报表两页挪进管理；技术提醒和布防模式切换先放「管理 → 提醒」（第二期换成「家里的状况」）。
- **值班页**（默认首页）：两个画面位按紧急程度自动挑、能钉住；前摄像头大、后摄像头小窗点了互换，装了热像的有「热像」按钮；断流停在最后一帧、变灰写已断几秒。下半屏每台一条状态 + 地图（报警的防区标红、平时只看）。红色横幅：我来处理 / 确认有人 / 误报（先确认）/ 处理好了，迷路了的多「帮它找位置」；别人处理掉了只提示一次。
- **实况页**：2×2 卡片前后并排一直在播，按紧急程度排；卡片「热像」按钮、右上角「全部看热像」。
- **地图页**：图层开关（防区和布防、巡逻路线和下一个点约几分钟、待命点、今晚的事、多久没巡过、禁行区默认关）；今晚的事列表点了看录像；点图问最近的机器人、确认才派；保安「按几个点走一趟」；不是布防时有「全部布防」。不显示定位质量、近 7 天定位问题。
- **录像页**：机器人按钮选、前 / 后 / 热像；大画面 + 另一路小窗（同一刻）；播放 / 暂停、倍速、±10 秒、截图、导出这一段（业主）、留作证据；右边地图那一刻在哪（之前实线、之后虚线，点轨迹跳时刻）；底下每台一行的时间轴（报警红、需要帮忙橙），滚轮拉宽拉窄。
- **报警记录页**：本班（7:00 / 19:00 交班）统计三个数、上一班留的话、给下一班留话；筛选本班 / 今天 / 日期 × 类型 × 只看没处理的；每行抓拍、时间、什么事、结论和谁、看录像 / 去处理；截了写明；技术类不列。

## 我替用户定的（Rulings）

1. 改词扫描的范围：站点、代理、契约里除文档字符串外的所有字符串（告警标题写在表里、异常文字也给人看）；`docs/` 和机器人上的工程师命令行不改。
2. 表里没列的几种告警：`battery_swap`、`standby_failed`、`lease_expired`、`suspend_stale` 给保安（需要帮忙）；`authorized_person`（授权的人在场，P3）归「有人闯入」，只进报警记录不弹横幅；`finding`（巡检照片异常）、`payload_amp` 给业主。
3. 旧报警卡片里的「定位那一行」、地图页右侧选中机器人的小画面和定位信息去掉（保安页不显示定位质量）；迷路由横幅 +「帮它找位置」处理。
4. 网页上不再有 P2「搁置」入口（站点接口还在）。
5. 地图页点图 = 让最近的机器人过去看看；「去这里 / 在这里设位置」只在值班页「帮它找位置」时用。
6. 摄像头图层这一期不出（站点还不知道摄像头在图上的位置，第三期「布置」才标）。
7. 授权「此刻生效」由站点算（`active_now`），网页不自己算星期和时区。
8. 「多久没巡过」的格子在 Python 里算，不用 SQLite 的 floor（CI 上不一定有）。
9. 录像页换机器人接着同一刻放（原来是停下）；去掉下面「这一天的报警」表（时间轴上有记号）；「导出这一段」= 直接下载这一段 mp4，只给业主。
