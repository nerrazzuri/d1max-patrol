# POC 当天操作单（只用网页和手机，不碰终端）

周计划 2026-11-05 至 11-08 第六节。照这张单子走，全程不 SSH。完成标准：演示站点上照着走一遍。

出厂前装机时一次填好的（不在当天做）：站点地址、机器人到站点主机的固定路由（`NEXWAR_ROUTES`，
例如 `192.168.234.0/24 via 192.168.168.168`）、竞品上装配置（含音量控件名，只在 POC 分支）。
站点主机要用 `deploy/site/install-site.sh` 装（会生成站点的三把密钥；手工起的站点会一直报缺 secrets.key、
evidence.key，现场第 28 条）。设备 PIN、密码都不写进这张单子。

## 一、开机（机器人自己完成，等约 2 分钟）

开机后机器人自己做这几件事，网页、手机上不用点：

1. 开机准备（不等代理）：
   - 加上装机时写好的固定路由（视频、站点连接用）；
   - 厂家的 chrony 在跑时，运行时给它加站点主机这个对时源（不改厂家的配置文件）；
   - 厂家用不上的服务（厂家 Nav2、建图、感知等）关掉开机自启：默认关，直到 V2 上装有了，可以在设置里开回去；
     跟图像解码同一个服务的不碰。
2. 等钟对上再起代理（开机钟是 1970 时不会反复重启）。
3. Nav2 起不来时自己重来；连着两回不成，整个 Nav2 服务自动重启。
4. 设置里开了「开机暂停厂家进程」才暂停（默认关）。
5. POC 分支：登录竞品主控把音量调到配置的百分比；盯求助、急停按钮。

**看什么**：网页「机器人」页卡片变成在线；卡片上没有「Nav2 不可用」。

## 二、开机检查（网页）

1. 机器人详情：电量、定位状态、地图版本对不对。
2. 「诊断」页 → 这台机器人 → 诊断快照：服务都是 active，时间已同步。
3. 有服务不是 active：同一处选服务 →「重启服务」；还不行 →「重启机器人」（要再输一次自己的密码，空闲才可以）。

## 三、设置（网页或手机，第一次上场或要改时）

「诊断」页 → 这台机器人 →「机器人设置」：

| 设置 | 说明 |
|---|---|
| 人员检测 | 开：看见人报警、云台对准（POC 分支） |
| 障碍净空许可 | 开：感知给旁路发许可，前进按许可放行 |
| 前进速度上限 | 50% / 70% / 100%；超过 50% 要先开障碍净空许可 |
| 开机暂停厂家进程 | 默认关；POC 前由用户决定要不要开 |
| 厂家用不上的服务开机自启 | 默认关（用户 11-06）；开回去会把关过的那些服务恢复自启并当场起来 |

保存要再输一次密码；机器人要空闲。保存后相关服务和代理重启，约 1 分钟离线，然后自己回来。

## 四、地图（上场前）

- 地图上有残影（现场没东西、图上是障碍，机器人停在旁边就规划不出，现场第 9 条）：网页「地图」→ 这一版 →
  「编辑」→ 橡皮擦把那一块擦掉（画一圈首尾接上，圈里整块擦）→ 另存成新的一版 → 给机器人换上这一版。
  原来那一版不动，擦错了换回去就行。

## 五、站起、定位

1. 手机遥控页或网页机器人详情：「站起」（先弹确认）。
2. 定位不可信时：机器人详情「自动定位」；不行就在地图上设位置，设完原地静止约 10 秒。

## 六、巡逻与演示

1. 网页机器人详情 → 选路线 →「开始巡逻」。路线编辑里标黄的点（贴墙又要原地转）先挪开。
2. 警灯与喊话：机器人详情「警示」一栏开警灯、打字喊话、放录好的话术。
3. POC 分支：
   - 云台：方向键（左右每下 15°、上下每下 10°）、「回正」、「雨刷」（刷 10 秒）。
   - 看见人：云台自己转过去；转过之后要手动调，先点「回正」。
   - 求助按钮：站点出 P1「现场有人按了求助按钮」，保安处理了才关。
   - 急停按钮：机器人当场停，站点叫停这台并出 P1；确认安全后机器人详情点「恢复」。
4. 手机遥控：按速度档走；遥控结束自动回低速档。

## 七、收尾

1. 机器人详情「回原点」（或「中止并回原点」）。
2. 到了以后「趴下」（先弹确认）。
3. 站点主机掉线时，手机值守页顶上会出红色横幅「从 HH:MM 起连不上站点主机」。

## 出问题时

| 现象 | 在哪处理 |
|---|---|
| 服务卡住、Nav2 一直不可用 | 诊断页「重启服务」（Nav2 自己也会整个重启） |
| 机器人整体不对 | 诊断页「重启机器人」（要密码，空闲才行） |
| 要看原因 | 诊断页按服务、时间段取日志，可下载 |
| 时间不对 | 诊断页「立即对时」 |
