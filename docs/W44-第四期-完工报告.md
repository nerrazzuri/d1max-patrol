「管理 → 高级」（默认收起来）五页，每页开头一句「什么时候用得上」：**地图、定位、诊断、软件升级、系统**；加一个从「地图」打开的**地图编辑器**。

**站点后端**

| 新东西 | 做什么 |
|---|---|
| 地图编辑 `map_edit.py` | 橡皮擦（改成空地）、画障碍（改成占用），画笔 / 直线 / 方框、粗细 0.05–2 m；跟清噪点一样**另存成新的一版**，原版不动；栅格摘要对不上回 409。只改 `floor.pgm`，不改 `prior.mm` |

| 报警「在哪」 | 告警现场带 `where`：命名区域，没命名用防区名 |
| 网页换图要密码 | 网页上发布地图（换图）要 `confirm_password`；手机照旧 |
| 网页上传升级包 | `POST /api/releases/upload`（请求体就是 `.tar.gz`，≤ 500 MB，密码放 `X-D1Max-Confirm` 头）；逐个核包里的路径（不许往外跳、不许链接），走跟命令行同一个登记（照旧验签、核指纹）；错了说人话（签名对不上 / 包坏了 / 已经有了） |
| 等充完电空闲时换 `release_queue.py` | `activate` 带 `when: "charging"` 排队；机器人在线新鲜、没任务、电量 ≥ 80% 才发，收下了出队 |

**网页**

- **地图**：重新建图五步（第 2 步在手机上遥控，网页只写怎么做）；每版加「编辑…」；发布对话框里再输一次密码。
- **定位**：每台绿「知道自己在哪」/ 黄「不太确定」/ 红「迷路了」/ 灰「不知道」；「帮它找位置」跟值班页同一套；历史和数字收在「详细」里。
- **诊断**：站点检查单（大白话，通过 / 不通过 + 说明）、每台机器人的设备检查单（摄像头有画面、连得上路由器、卫星定位、存储盘……）、打包日志下载。
- **软件升级**：现在的版本、上传升级包（再输密码）、在线下载灰着（W45）、每台「下载到机器人」「现在换」「等充完电空闲时换」「退回上一版」、谁还在用老 App。
- **系统**：站点名、时间、版本、存储、证书、证据加密、备份（没成功写红）、外网和 VPN（写明还没装，W45）、手机配对。
- **地图编辑器** `#/admin/mapedit?map=…&version=…`：橡皮擦、画障碍、画笔 / 直线 / 方框、粗细、区域命名、特殊地面（种类、放慢多少）、摆正（只转显示）、底图（上传、位置、比例、转角、透明度）、撤销重做；
  「另存成新的一版」前列出大约擦了多少、画了多少要确认；只改显示的不另存新版本；页面写明改的是平面图不是立体地图。虚拟墙、禁行区去「布置」。
- 禁行区标签也能画抹掉区（第三期留下的）。

## 我替用户定的（Rulings）

1. 「等充电时装」做成「等充完电、空闲时换」：换版本要机器人空闲，充电那一趟本身是任务，在桩上换不了。机器人一直不空闲就一直排着。
2. 底图只在地图编辑器里看（给业主对齐用），保安地图页不画。
3. 报警「在哪」只给以后的告警带上；以前的告警没有。
4. 清噪点没放进编辑器，留在「地图」页每一版的「清噪点…」（外审过，自己另存一版）—— 避免一次编辑出两版。
5. 画笔是点几下连成一笔，不是按住拖（地图组件给的是点击；触屏也好用）。
6. 上传升级包先收完文件、再验密码：没读完就回「密码不对」的话，浏览器多半只看到「连接断了」。代价是密码输错时也白传一次文件（局域网里几十秒）。
