# 手机 app（`mobile/`）

**手机只连站点，不连狗。** 站点是庄园现场的一台主机（`packages/site-node`，命令 `d1max-site`），
它是唯一的权威：狗的状态、派单、告警、画面、遥控、运行记录与照片、地图、版本都在站点上。
狗上只跑代理（`d1max-agent.service`），经 MQTT（mTLS）连站点；手机从头到尾不知道狗的地址。

只做 Android。Flutter 3.47 / Dart 3.13（`pubspec.yaml` 要 Dart ≥ 3.13.2）。

## 现在有哪几屏

打开就是**站点列表**。点一个站点 → 输口令登录 → **狗的列表** → 点一只狗进**单狗页**。
狗的列表顶上一排入口：**值守、版本、地图、记录、事件、排程**。

| 屏 | 文件 | 做什么 |
|---|---|---|
| 站点列表 | `lib/ui/site_page.dart` 的 `SiteListPage` | 加站点（名字、`https://主机:8443`、证书指纹、账号）、删站点、点进去登录。保存前就校验地址和指纹，不等到登录才报错 |
| 狗的列表 | 同上 `SiteRobotsPage` | 每只狗一行（在线／离线／在跑什么）。**实时**：站点的事件流（SSE）一来就刷新；断了顶上挂一行「实时更新没连上，正在重连」，5 秒后自己重连，下拉也能手动刷。令牌失效（401）就退回站点列表，要重新登录。**升到声音档、还没人确认的告警**由这一屏响铃（系统提示音 + 震动），不管人此刻在看哪一页；连上、重连上时再补查一次，断线期间错过的那一帧不会就此不响。App 没开时的系统推送还没有 |
| 单狗页 | 同上 `SiteRobotPage` | 状态一行；按钮按角色给（见下表）：派巡检（从站点的任务里挑一趟）、遥控、开始／停止录包（只有这只狗报了建图能力才显示）、回待命点、叫停（正在跑任务时才出现；按之前**现取**一次正在跑的任务号，不用屏上几秒前的那个）。按钮下面是画面，再下面是最近 30 条事件。**叫停放在画面上面**：要一眼按得到，不许被画面挤出屏幕 |
| 事件、排程 | 同上 `SiteIncidentsPage`、`SiteSchedulePage` | 外部事件派遣的账；站点当前任务包的排程（下一轮、上一次结果） |
| 值守 | `lib/ui/site_watch_page.dart` | 从上往下三件事：**有没有要我动身的 P1**（一条都没有也写「没有」；还没读到过写「还没读到」，两句话不许混）、其余未解决告警、**每只狗和站点自己有没有在悄悄坏掉**（在线、电量、钟偏、未解决告警、盘水位、证据积压；站点那一行是排程与备份）。缺的数一律印「不知道」和理由，不写 0。屏上写着「告警读于 几点几分」；实时更新之外每 30 秒再问一次。保安、管理员能确认、解决告警，确认人由站点从令牌里取 |
| 画面 | `lib/ui/site_video.dart` | 前、后两路切换。画面经站点转来（MJPEG），取流用钉住站点证书的客户端。「在不在线」按每 2 秒问一次站点这只狗新不新鲜来判，**不问画面健康**：站点要有人来拉流才让狗开始推，拿画面健康当开流条件，两头就互相等，画面一次都起不来。页面被盖住时自己断开（`widget/live_video.dart`），站点那头最后一个观众走了狗就停推 |
| 遥控 | `lib/ui/site_teleop.dart` | 见下面「遥控」一节 |
| 记录 | `lib/ui/site_runs.dart` | 每一趟一行（任务、时间、几张照片、判读结论、复核了几张，有异常标红）→ 一趟的照片列表 → 单张照片：模型的结论（把握、理由、依据）和人的复核。**人的复核优先**：模型判的是「先看哪几张」。保安、管理员能复核（正常／异常／看不清，可以说一句）、让站点重判这一趟。照片带令牌、钉证书取，单张上限 20 MB |
| 地图 | `lib/ui/site_maps.dart` | 站点上的图（地图号:版本、从哪来、几个文件）和录包。管理员点一张图 → 挑一只报了换图能力的狗 → 再确认一次 → 狗后台下载、核对、载入；点一个录包 → 在录它的那只狗上重建一张新图（要给一个新版本号）。录包的开始、停止在单狗页 |
| 版本 | `lib/ui/site_releases.dart` | 站点上登记过的每一版；每只狗在跑哪一版（狗自己报的，没报就写「不知道」、不给按钮）。管理员：装（狗后台下载、核对、落槽、建 venv，不切）→ 切 → 不对劲就退。切和退要再确认一次：狗要重启代理，跑着任务时狗会拒 |

**按钮按角色给，真正的权限在站点上**（站点回 403）。这里只是不给人一个注定被拒的按钮。
角色是站点账号上的（W00c3），三个固定的：

| 能做什么 | 管理员 admin | 保安 guard | 业主 owner |
|---|---|---|---|
| 看狗、看画面、看值守、看记录、看地图、看版本 | ✓ | ✓ | ✓ |
| 叫停正在跑的任务（单狗页「叫停」） | ✓ | ✓ | ✓ |
| 派巡检、回待命点 | ✓ | ✓ | |
| 遥控（遥控页里有「停」） | ✓ | ✓ | |
| 确认、解决告警；复核照片、让站点重判 | ✓ | ✓ | |
| 下发地图、录包、重建；装、切、退版本 | ✓ | | |

站点那头的 `halt`（停车）业主也有权限；手机上它只挂在遥控页里，业主进不了遥控页，
业主手上的是单狗页的「叫停」。**不管哪个角色，第一手段永远是机身硬急停。**

## 遥控（决策 7）

遥控只经站点，规矩在决策 7（用户批准、外审批准），手机这头落实的是：

- **连接就是租约。** 进遥控页开一条到站点的 WebSocket（`GET /api/robots/<id>/teleop` 升级）；
  退出、断线都放租，狗停。被拒的时候站点给状态码和原因（「某某正在遥控」），屏上照说。
- **左杆只管前后**（狗不横移），**右杆只转向**。按住每 100 ms 发一帧（带自己的序号和单调钟时刻），
  松手发零速。限速是这只狗能力的一半：站点夹一次、狗那头再夹一次，手机不自己定。
- **大红「停」钉在最底下，走站点的 `halt`，不走遥控连接**：连接卡住的时候正是最需要停车的时候。
  按下去先在本机收手（停发帧、发一帧零速、放租），再发 halt；halt 发不出去就弹一句「按机身急停」。
- **没有画面，不许动。** 站点说画面没了，杆当场变灰、归零、补发一帧零速；顶上一行红字写
  「没有画面：不许动」。遥控结束（放开、断线、被管理员接管、有人按了停车、狗掉线、续不上租约、
  登录过期）也是杆变灰，并说是哪一种。
- 帧的有效期、序号、积压、限速、没推流不动这些规矩**由狗那头的代理执行**，手机和站点只是前两道。
- 客户端留了管理员带理由强制接管的参数（`SiteApi.teleop` 的 `takeoverReason`），**界面上还没有入口**。
- **切后台、锁屏这一页没有专门处理。** 兜底在另两头：狗那头每帧有效期 300 ms，站点 3 秒收不到心跳就判连接死、放租。
  所以纪律照旧：握着杆的时候不锁屏、不接电话、不切出去；要离手先松杆、看着狗停住。

真机上还没验的（延迟、4G 抖动、断网、业主按停、巡检中接遥控、半速够不够）在
`docs/庄园场景待真机测试.md` §3c（3c.8–3c.16）。

## 站点列表存什么（`lib/store/site_store.dart`）

每个站点一条：

| 字段 | 是什么 |
|---|---|
| `name` | 现场叫它的名字 |
| `url` | `https://主机:端口`（站点 API 默认 8443）。**只收 https**：口令不能明文过网 |
| `fingerprint` | 站点服务证书的 SHA-256，站点主机上 `d1max-site fingerprint` 打出来的那串。粘进来时带冒号、空格、`sha256:` 前缀都行，存的是 64 位小写十六进制 |
| `username` | 登录用的站点账号 |

- **口令不存**，每次登录现输；**令牌只在内存里**。离开狗的列表就注销，不然令牌在站点上还能用半小时。
- 文件是 app 私有 documents 目录里的 `sites.json`（`lib/store/paths.dart`）：别的 app 读不到，卸载 app 跟着删。
  不放外部存储：那里别的 app 能改，地址或指纹被改掉就意味着连错站点。
- **写是先写临时文件再改名**，掐电不会留半截。
- **文件读不出来要明说，而且这时候不许加、不许删**：一保存就把坏文件里其余的站点覆盖掉了。

## 跟站点说话（`lib/net/site_client.dart`）

- **只认一张证书。** 站点用自己的 CA 签的证书，系统不认识它；这里不装 CA，而是把站点服务证书的
  SHA-256 钉死。`SecurityContext(withTrustedRoots: false)` 让**每一张**证书都走钉扎回调，
  包括系统碰巧认识的 —— 不然系统信任的证书会绕过钉扎。对不上就断，报错里带上实际见到的指纹。
  钉的是服务证书本身不是 CA：**站点证书重签之后，手机上要把这个站点删了重加**。
- **重定向一律不跟**（3xx 也算错）：重定向可能把人带到别处，甚至 `http://`。
- **超时 25 秒**，比站点等狗回执的 10 秒加余量长。短了会把「站点已经派出去了」报成超时，人再按一次就派了两趟。
- **401 就作废令牌**，界面退回登录。站点的令牌有两道期限：闲置 30 分钟、绝对 12 小时。
- **事件流（SSE）**：第一帧是全量快照，之后是状态、事件、告警……站点每 15 秒发一行心跳；
  45 秒一行都没来就当断了，调用方照常重连。不这样的话换网之后连接半开，屏上长期停在旧数据上。
- **读不懂就抛，不当成「没有」**：告警、运行记录、地图目录、发布目录的回包缺了该有的键，一律抛
  `FormatException`，屏上报错（值守屏写「告警读不懂」），**绝不退回一份空名单** ——
  空的 P1 列表是值守屏能说的最坏的假话。

## 手机的「现场直连」为什么删了（W00c5e）

W00c4 加站点模式的时候，直连狗的那几屏（狗的名册、设备 PIN、连狗热点、直连遥控、控制权面板、盘况屏、
`patrol_client.dart`）先留着，标为过渡。W00c5e 把它们连同 `flutter_secure_storage`（只有 PIN 用）整个删了：
**手机从此不跟狗说话。** 决策 7 之后遥控只能经站点、有租约、有审计、由狗那头的代理判帧，直连遥控这几样都没有，
不能留一个还打得开的入口；决策 8 之后数据、判读、备份都在站点上，狗上那几屏看的东西也已经不在狗上。
老版本存在手机里的名册和 PIN 没人再读，不做迁移，卸载 app 时一起没了。

## 在这台机器上怎么跑

Flutter 没装进系统，也不在 PATH 里，每次显式加。现在这台 Ubuntu 开发机上用的是解到任务临时目录里的
Flutter 3.47.5 / Dart 3.13.4（W00c4 起）：

```bash
export PATH="<Flutter 解压目录>/bin:$PATH"
cd "<仓库>/mobile"

flutter analyze                  # 期望：No issues found!
flutter test --concurrency=1     # 期望：退出码 0，一条不红
```

**这台 Ubuntu 机器编不了 APK**：`/usr/lib/android-sdk` 里只有 `platform-tools`（adb），没有构建工具和平台。
编包要在装了 Android SDK 和 JDK 的机器上跑 `flutter build apk --release`。原来那台 Windows 开发机是这么配的
（Android SDK 和 JDK 用 Android Studio 自带的那套）：

```powershell
$env:PATH = "D:\toolchain\flutter\bin;$env:PATH"
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio1\jbr"
cd "D:\Projects\D1 Max\d1max-patrol\mobile"
flutter build apk --release
```

编出来的包用 `aapt2 dump permissions <包>` 核一下有 `android.permission.INTERNET`（清单里有这一行，
2026-09-15 出过一次没带它的包，装上连不上）。**`dist/app-release.apk` 是直连模式那一版，W00c5e 之后不能用**，
要装站点模式就得重编。

> **这里故意不写条数。** 一个写在命令注释里的条数，唯一的作用是过期之后误导下一个人：
> 他看见的数跟注释对不上，会以为自己跑错了，或者反过来，以为「少跑几条也算对」。
> **判据是退出码，不是条数。**

**`--concurrency=1` 不是可选的。** 裸跑 `flutter test` 会间歇性**无声吞掉字母序最后一个测试文件**，
并且照样打印 `All tests passed!`。少跑了一整个文件而汇总说全过 —— 这是「测试说谎」最便宜的一种版本，
所以这条写死在这里。已知还有一条偶发红的老测试：`live_video_test.dart` 的
「盖住的页面退掉之后画面自己回来」（W00c4 起记着）。

**这套测试跟 Python 那套是两码事，各跑各的。** `pytest` 不碰 `mobile/`，`flutter test` 也不碰 `packages/`、`src/`。

**契约怎么钉住的**：`mobile/test/fixtures/site_*.json` 是**站点那头从真的站点 API 取出来的**
（`packages/site-node/tests/test_site_mobile_fixtures.py`，比的是形状不是值）；站点改了报文形状，
Python 那侧先红，`D1MAX_WRITE_FIXTURES=1` 重新生成之后 Dart 这侧接着红。测试里的假站点
（`test/support/fake_site.dart`）是**真的 HTTPS**，用自签的 `test/support/site_test.crt`，钉扎走的是真路径。

### 踩过的坑

- **Dart 的标识符不认中文。** 测试名（字符串）可以是中文，变量名不行 —— 写了会报 `illegal_character`。
  中文只留在注释、文档注释和字符串里。
- **仓库路径里有空格**（`D1 Max`）**不是问题**，测试和编包都照常，不用搬。
- **widget 测试里推真网络有三个坑**，都收在 `test/support/pump.dart`，共用、不许各人复制一份：
  `flutter_test` 把 `HttpOverrides.global` 换成了全回 400 的假件；真 I/O 只在 `runAsync` 里推得动而
  `runAsync` 里又不许 pump；`testWidgets` 里 `await` 关流会永远卡住。
