# 手机 app（`mobile/`）

最终形态是**不带笔记本**：脑子跑在狗自己的 Orin NX 上，手机当遥控器。
这个目录是那个遥控器。

只做 Android。Flutter 3.47.2 / Dart 3.13.2。

---

## 现在做到哪儿了

**四屏：名册、遥控、控制权面板、盘况。**（第 7 卷做完，2026-09-09）

**那个岔路口已经过了：操作界面是原生做的，不套 WebView。**
原先这里写着「等现场答一下手机浏览器好不好用，好用就把狗身上那个网页版嵌进来」。
第 7 卷按规格 §7.7 走了原生这一边，理由是遥控这一屏的三件事 ——
**视频要铺满、摇杆要跟手、松手要立刻停** —— 在 WebView 里都得过一层 JS 桥，
而那层桥的延迟正好加在「松手到狗停住」这条最要命的路径上。

### 一、鉴权：PIN 从不上网

走**质询-应答**：`GET /api/auth/challenge` 拿 nonce →
本地算 `HMAC-SHA256(PIN, nonce)` → `POST /api/auth` 换 token。
**PIN 本身一个字节都不上线。**

- **跨语言向量在 `mobile/test/fixtures/proof_vectors.json`**，狗那头生成的。
  两侧算出来的证明必须逐字节相同 —— 这份文件就是那条契约的钉子。
- **狗回的质询缺字段时直接抛错，绝不退回 `{'pin': pin}` 那条老路。**
  那条老路狗会静默降级成只读凭证，现场看到的是「遥控全部 403」，
  报错指向权限而不是「PIN 明文发出去了」，比一个裸的类型错误更难查。
- 解锁要报一个 `operator`（操作员名字）。**狗记下来但从不核实**
  （`operator_verified` 恒为 `False`），它是审计用的，不是身份。
  现在的形态是「会话内问一次、不落盘」，**暂定，没有规格依据** ——
  见 `docs/第2卷待办.md` 挂账 65。

### 二、遥控屏（`ui/teleop_page.dart`）

- **视频铺满**，两个虚拟圆心摇杆浮在上面：**左平移（吸单轴）/ 右只转向**。
- **持续发拍**，一拍一拍地喂 `POST /api/teleop`；
  **松手那一刻主动发一次全零停**，并在接下来两个周期再补两拍全零
  （合计 3 拍约 0.6 秒）—— 松手那一拍要是丢了，就只剩狗那头 0.6 秒的守死人兜底，
  而那半秒足够撞上东西。
- **两道闸各有各的话，不许合成一句**：**没有控制权**是一句，**没有画面**是另一句。
  合成一句的话，人看到「杆是灰的」却不知道该去取控制权还是该去查相机。
- **杆变灰的那一刻要把杆归零**，因为人手里可能还推着。
- **现场档 / 远程档**（§7.8）：两档只差发拍的节奏。**切到远程要确认一次，
  而且只问一次** —— 每次都问的确认框，人会学会闭着眼点。确认这件事自动写进留痕。

### 三、控制权面板（`ui/control_panel.dart`）

取 / 还 / 接管，外加一个倒计时。

- **倒计时读狗给的 `expires_in_ms` 相对量，本地每秒减一格，隔一阵跟狗校准一次。**
  **绝不拿绝对时刻去减手机自己的钟** —— 狗上没有 NTP，两边的钟必然对不上。
  **校准周期不是拍的，是狗说了算**：`heartbeat_ms ~/ 3`
  （见 `ControlPanel.syncPeriodFor`）。狗那头今天 `LEASE_HEARTBEAT_MS = 10_000`，
  所以约 3.3 秒一次；狗哪天改了这个数，手机跟着变，不用改 app。
- **三条路各占一个话槽，每个槽有自己的 key**：发拍失败、心跳失败、续期失败。
  挤一个槽的话两条路会互相抹，人看到的是一行在闪 ——
  闪着的字比没有字更容易被当成花屏。（这个形状在本卷复发过四次，
  见 `docs/测试为什么会说谎.md`。）

### 四、盘况屏（`ui/storage_page.dart`）

**只读。不给清盘入口，也不轮询。**
屏上有一行静态指路，告诉人清盘要去狗身上的网页端做。
为什么只看不删：这一屏防的就是「在手机上误删一整趟巡检」。
详见 `docs/第2卷待办.md` 挂账 15。

## 为什么名册必须在手机这边

每只 D1 Max 的内网地址**都一模一样**：RK3588 `192.168.168.168`、
Orin `192.168.168.100`、WiFi 侧 `192.168.234.1`。这是机器里写死的，不是我们
配的。所以：

- **地址分不出谁是谁。** 三只狗，三个一模一样的网址。
- **一次只能连一只。** 手机连的是狗自己开的热点，同一时刻只在一个热点上。
  所以名册不是"同时监控 N 只"的面板，是"我要去哪只"的选单。
- **只有手机知道全局。** 每只狗只知道自己是谁（`GET /api/identity`），
  它不认识别的狗，也没道理认识 —— 客户买三只，三只之间没有网络往来。

服务端那边对应的实现在 `src/d1max_patrol/app/identity.py`，同一套道理。

## 名册里存什么

以 **SN 为主键**。每条：

| 字段 | 是什么 |
|---|---|
| `sn` | 机身序列号。机器上跑 app 时用 `D1MAX_SN` 填的那个。不能为空 |
| `name` | 现场喊的名字，比如"三号"。可以不填 |
| `ssid` | 热点名，形如 `XG2WIFI_C40221` |
| `bssid` | 热点的 MAC。**连上之前就看得见**，所以能先认出是谁再决定拿哪个 PIN |
| `host` / `port` | 服务端在哪，默认 `192.168.168.100:8095` |

**PIN 不在这张表里。** 它走系统密钥库（`SecurePinVault`，Android Keystore
后面的 `EncryptedSharedPreferences`），名册文件里从头到尾看不见它 ——
名册会被导出、会被贴进工单、会跟着备份走，钥匙跟进去一次就收不回来。
`test/store_test.dart` 里有一条测试直接去读落到盘上的那串字节，确认搜不到
PIN。

几条刻意做出来的选择：

- **重复登记会被拦住，不静默覆盖。** 覆盖掉的是已经调好的那条，而界面上
  看起来一模一样，人不会发现。改已有的要点那一条进去改。
- **一个 SSID 对上两只狗时不许随便挑一只**，直接把歧义顶到界面上。挑错了，
  操作员就在错的狗上按了"跑"，而他不会知道。
- **删一只，PIN 跟着忘掉。** 条目没了钥匙还留着，是一份界面上看不见、
  因此谁也不会想起来删的残留。改 SN 也算换了一只，同理。
- **名册文件坏了要明说，不能装成一本空的。** 装成空的，人就会以为自己从来
  没登记过，然后重新填一遍，而坏掉的文件还躺在盘上。
- **写是先写临时文件再改名。** 手机随时没电，写到一半的 JSON 下次打开就是
  "我的狗全没了"。

## 在这台机器上怎么跑

Flutter 装在 `D:\toolchain\flutter`（不在 PATH 里，每次显式加）。
Android SDK 和 JDK 用 Android Studio 自带的那套。

```powershell
$env:PATH = "D:\toolchain\flutter\bin;$env:PATH"
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio1\jbr"
cd "D:\Projects\D1 Max\d1max-patrol\mobile"

flutter analyze                  # 期望：No issues found!
flutter test --concurrency=1     # 期望：退出码 0，一条不红
flutter build apk --debug
```

> **这里故意不写条数。** 原来写的是「期望：185 条全过」，
> 那个数在第 7 卷终审当天就变成 191 了，之后又变成 262 ——
> **一个写在命令注释里的条数，唯一的作用是过期之后误导下一个人**：
> 他看见 262 而注释写 185，会以为自己跑错了，或者反过来，
> 以为「跑出 185 也算对」。**判据是退出码，不是条数。**
> 当前的条数在 `docs/分卷与进度.md` 那张基线表里，那份是有人负责更新的。

**`--concurrency=1` 不是可选的。** 这台机器上裸跑 `flutter test` 会
**无声吞掉字母序最后一个测试文件**，并且照样打印 `All tests passed!`。
少跑了一整个文件而汇总说全过 —— 这是「测试说谎」最便宜的一种版本，
所以这条写死在这里。

**这套测试跟 Python 那套是两码事，各跑各的。** Python 的 `pytest` 不会碰
`mobile/`，`flutter test` 也不碰 `src/`。

### 踩过的坑

- **Dart 的标识符不认中文。** 测试名（字符串）可以是中文，变量名不行 ——
  写了会报 `illegal_character`。所以数据用 `_sanHao` 这种拼音名。
- **仓库路径里有空格**（`D1 Max`）**不是问题**，APK 照样编得出来，
  连 NDK r28c 装在带空格的 SDK 路径下也没事。不用搬。
- **`flutter_secure_storage` 卡在 v9。** v11 要求 `compileSdk = 37`，
  而 AGP 9.1 官方推荐上限是 36，本机也只有 android-37.1 这个预览版平台。
  交付给客户的东西不压在预览 SDK 上。等 AGP 正式支持 37 再升。
- **v9 的 `encryptedSharedPreferences: true` 必须显式打开。** 这个插件在
  Android 上的默认行为是普通 SharedPreferences，也就是**明文**。不写那一行，
  PIN 就是纯文本躺在私有目录里，整个 `SecurePinVault` 等于白写。

**`net/wire.dart` 为什么全是只读模型**：真理源在狗身上，手机改了也不算数。
能改的模型只会诱使人在界面上先改再发，而那两步之间的窗口里，
屏幕上显示的是一件没发生的事。

**契约怎么钉住的**：`mobile/test/fixtures/*.json` 那八份是**狗那头生成的**
（`tests/app/test_wire_fixtures.py` 从真的路由处理器里取输出），
`mobile/test/wire_fixtures_test.dart` 拿它们喂 `wire.dart` 的各个 `fromJson` 解一遍。
**狗那侧 `to_wire()` 改一个字段名，Python 侧当场红；重新生成夹具之后 Dart 侧接着红。**
这就是挂账 11 要的那件事。

## 解锁之后还有第二道闸：控制权

**拿到 token 只等于「能看」，不等于「能动」。** 一只狗同时只有一个人能改变
它正在做什么，那份权限叫 **L1 控制权**，要单独去取（`POST /api/control/acquire`），
30 秒到期，每 10 秒发一次 `POST /api/control/heartbeat` 续。

做操作界面时这三条会直接撞上来：

- **受控接口在没取控制权时回 HTTP 409**，错误文案是「先取控制权」。遥控走一
  拍、起任务、暂停／中止、换地图、设初始位姿都在这一档。**409 要照文案分**：
  闸门说的那句是「去取控制权」，业务说的那句（比如「没在跑」）是别的意思 ——
  两者状态码一样。
- **一条不存在的受控路径现在也回 409，不是 404。** 闸门排在路由匹配之前，跟
  「没解锁时一律先 401 而不是 404」是同一条立场：不给未授权的人当存在性探针。
  所以 app 别拿 404 来探「这台狗支不支持某个接口」，探不出来。
- **看和急停永远不要控制权。** 画面、状态、报告随便看；`POST /api/estop`
  **只要你已经连上了**就任何时候都按得下去，包括控制权在别人手上、包括只读
  凭证。**前提是「已经连上」** —— 三个远端名额满了的时候，第四个人连 token
  都换不到，也就按不了急停，那时候按机身上的物理急停。

**热点上不是只能看。** 手机 app 走的是质询-应答，在狗自己的热点上换到的也是
**完整凭证**，能动机器；「只换只读」说的是内置网页上敲明文 PIN 那一路。客户网
崩了的时候，连热点用 app 就是那条应急通道。

全部规矩（三个时间尺度、接管怎么走、热点上用明文 PIN 为什么只换只读凭证）见
`docs/鉴权与控制权.md`。
