## 附：现场补出厂证书（贴文字，1.3b）

出厂申请和签好的证书都不含机密，各是一小段 JSON。**出厂私钥 `factory.key` 只在台式机上，不拷、不传。**
`<编号>` 是 C40221 在这次新装的站点上登记的机器人编号（站点核的是它）。

1. **机器人上**（笔记本 SSH 到 Orin，先装好 1.3 的新包）：
   ```bash
   sudo /opt/d1max/bin/python -m d1max_patrol.cli factory device-init --serial <编号>
   sudo cat /etc/d1max/device/device-request.json
   ```
   读不到芯片编号会直接报错、什么都不写 —— 把报错原样贴回来。
2. **贴给台式机**：把打出来的那一段 JSON 原样贴进 Claude 对话（手机上打开同一个会话也行），说「签 C40221 的出厂申请」。
3. **台式机上**（Claude 做）：存成文件，
   ```bash
   .venv/bin/python -m d1max_patrol.cli factory sign-device <申请文件> \
       --key ~/nexus-keys/factory.key --out-dir <临时目录> --ledger ~/nexus-keys/出厂台账.csv
   ```
   把 `<临时目录>/<编号>.json` 的内容贴回对话；`~/nexus-keys/factory-pub.pem` 也一起贴（公钥）。
4. **机器人上**：把两段分别存成 `cert.json`、`factory-pub.pem`，
   ```bash
   sudo /opt/d1max/bin/python -m d1max_patrol.cli factory install-cert cert.json --factory-pub factory-pub.pem
   ```
   打「装好了」就接着做 1.3c。打别的（序列号、芯片编号、设备钥匙对不上）原样贴回来，不要重复 device-init 换钥匙。

台式机和笔记本在同一个局域网时（在家、在公司），也可以在台式机上一条命令做完：
`tools/factory.py --board <机器人地址>=<编号> --identity-only --out /tmp/x`（`docs/出厂流程.md` 第三节）。现场一般连不到台式机，用上面四步。
