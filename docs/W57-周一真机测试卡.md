## 附：现场补出厂证书（贴文字，1.3b）

出厂申请和签好的证书都不含机密，各是一小段 JSON。**出厂私钥 `factory.key` 只在台式机上，不拷、不传。**
`<编号>` 是 C40221 在这次新装的站点上登记的机器人编号（站点核的是它）。

1. **机器人上**（笔记本 SSH 到 Orin，先装好 1.3 的新包）：
   ```bash
   sudo /opt/d1max/bin/python -m d1max_patrol.cli factory device-init --serial <编号>
   sudo cat /etc/d1max/device/device-request.json
   ```
   读不到芯片编号会直接报错、什么都不写 —— 把报错原样贴回来。
2. **贴给台式机**：把打出来的那一段 JSON 原样贴进 Claude 对话（手机上打开同一个会话也行），说「签 C40221 的出厂申请」。
3. **台式机上**（Claude 做）：存成文件，
   ```bash
   .venv/bin/python -m d1max_patrol.cli factory sign-device <申请文件> \
       --key ~/nexus-keys/factory.key --out-dir <临时目录> --ledger ~/nexus-keys/出厂台账.csv
   ```
   把 `<临时目录>/<编号>.json` 的内容贴回对话（装 rc.1+3 及以后的包时，`~/nexus-keys/factory-pub.pem` 也一起贴）。
4. **机器人上**：把证书存成 `cert.json`，
   ```bash
   sudo /opt/d1max/bin/python -m d1max_patrol.cli factory install-cert cert.json
   ```
   rc.1+2（`0d7956f3`）的包里 `install-cert` 还没有 `--factory-pub`（#244 才加），不要写；装包时 `install.sh`
   已经把出厂公钥放到 `/etc/d1max/factory-pub.pem`，不写也核得了。rc.1+3 及以后的包可以加
   `--factory-pub factory-pub.pem`（机器人上没装那份公钥时用）。
   打「装好了」就接着做 1.3c。打别的（序列号、芯片编号、设备钥匙对不上）原样贴回来，不要重复 device-init 换钥匙。

台式机和笔记本在同一个局域网时（在家、在公司），也可以在台式机上一条命令做完：
`tools/factory.py --board <机器人地址>=<编号> --identity-only --out /tmp/x`（`docs/出厂流程.md` 第三节）。现场一般连不到台式机，用上面四步。


**站点跑在现场笔记本上时**（不是 1.1 那台干净主机，机器人经 `ssh -R` 隧道连站点）：

- 站点 API 要走 https：`serve --api-host 127.0.0.2 --api-port 8443`（只绑 127.0.0.1 时是明文 http，机器人领证书连不上；
  127.0.0.2 也是本机回环，不暴露到热点网里）。隧道在 8883、8444 之外再加 `-R 8443:127.0.0.2:8443`；开通码里的
  地址是 `https://127.0.0.1:8443`，领证书只核指纹，不核主机名。网页改用 `https://127.0.0.2:8443`。
- 站点要认出厂公钥：`site.json` 加 `"factory_pubkey": "<仓库>/deploy/factory-pub.pem"`（缺省找
  `/etc/d1max-site/factory-pub.pem`，笔记本上没有 → 所有机器人都被拒）。
- 新代码第一次起会升级站点库，先备份站点目录。
