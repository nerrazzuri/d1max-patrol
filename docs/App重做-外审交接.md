# 手机 App 按设计稿重做（C-B5）：外审交接

> 范围 **`e0f829f..b20a8bc`**（PR #144–#147，22 个提交）。
> 来历：用户 2026-10-14 说 App V2「太丑了」，给了一份 FlutterFlow 做的设计稿（导出的代码），要求照它重做。
> **只换了表现层**：主题、组件、导航、每一页的布局。`mobile/lib/net/` 一行没动；站点、狗、网页值班台没动。
> 计划：`docs/superpowers/plans/2026-10-14-app-redesign.md`。台账 `C-B5`，决策 63。
> 做法：主会话写计划、审每一批、合并；每一批由一个子代理在自己的工作目录里做（P0 基础 → P1–P4 四批并行 → P5 收尾）。

## 用户定了的（决策 63）

1. 浅色、深色两套，跟随系统。
2. 按设计稿用绿色表示正常。红仍只给 P1 和急停类，橙只给 P2 和低电；优先级照旧「颜色 + 形状 + 文字」。**这改掉了手机上「正常状态不上色」那一条**；网页值班台不变。
3. 登录保留账号加口令（设计稿是数字键盘加指纹，没做）。
4. 字号按设计稿的比例，最小 12；告警页的标题、距离、按钮不低于 14。

## 2. 行为上的变化

- 登录后进的是带底部导航的外壳：值守 / 狗 / 地图 / 记录 / 管理（非管理员是「更多」）。原来狗列表顶栏那排入口没了。
- 登录是一整页；登录不了的原因写在这一页上。
- 值守首页可以直接切布防模式。
- 狗列表有本地筛选（全部 / 执行中 / 充电）；狗卡上有电量。
- 单狗页没任务时有一个置灰的 STOP（Key `btn-abort-off`）；有任务时才有 `btn-abort`。
- 地图栏直接显示「多数狗在用的那张图」；没有狗在用就显示站点最新的一张并说明。
- 主题跟随系统；字体换成 Space Grotesk / Inter / JetBrains Mono（打在包里，包大了约 1.2 MB，删掉老字体后净增不到 1 MB）。
- 站点 API、协议、库：**没变**。

## 5. 跟设计稿不一样的、没做的

- 遥控：摇杆在画面两侧，不是叠在画面上（安全几何测试）。没有速度、俯仰、航向、高度、延迟、灯、喇叭（没有后端）。
- 告警页画面上没有「LIVE」和时钟（这一页确认不了画面是不是实时的）。
- 登录没有数字键盘、指纹、重置（决策 63）。
- 地图不是 Google 地图，是站点的栅格图；狗的位置进来时和点刷新时读，不自动更新。
- 巡检卡没有缩略图（列表接口只给张数）。
- 狗卡上没有「有 P1 / 翻倒」（狗的视图里没有）。
- 管理页没有「重启站点」（没有后端）。
- 截图里看得出的小毛病（没改）：告警页英文两个按钮折行；深色下栅格图是浅灰的；有异常的巡检整行都红；遥控两侧较空；长地址截断；横屏 360 高时值守首页首屏内容少。
- 网页值班台还是老样子（另一套令牌 `design/tokens.json`，没动）。
