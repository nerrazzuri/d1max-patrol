### 2.1 改了什么、行为变化

**定位（对账 S1、S2、S6）**

| 项 | 以前 | 现在 |
|---|---|---|
| S1 没参照位置时 | 代理刚重启、没有锚，定位器稳下来的位置**直接认**；里程断过（换段）也照认 | 只认一种：代理连上定位器以来**一次没跳过**（W34「代理重启不用人重给位置」照旧）。跳过、重定位过、里程断过又跳了 → 「请重新设位置」。锚（地图位姿 + 当时的狗里程）写盘 `/var/lib/d1max/agent/loc_anchor.json`，同一次开机、同一张图才用，**只拿来核、不直接认** |
| S2 建图手性 | 只按「地面在雷达下面」定「上」 | 打包前拿狗自己的里程（`/odom/mc_odom`，没有用 `/odom/current_pose`）比地图里的转向：1 s 窗口、允许 ±3 s 时差；≥80% 转角同向 = 对；≤20% = **镜像，不出图**；中间、转得太少（<57°）、没里程 → 照出图并写明原因。结果写 `build.json` 的 `handedness` |
| S6a 定位变差 | 只有「可信 / 不可信」 | 可信但在推算（数据旧过 0.5 s）或 σ > 0.25 m（丢定位线 0.5 m 的一半）→ 自主限速 **0.3 m/s**，好了再等 3 s 才放开；遥测多 `loc.degraded` |
| S6b 空闲丢定位 | 只在跑任务时报 | 狗空闲、`loc_ok=false` 连续 **120 s** → P2 `loc_lost_idle`；刚连上、开机号变了、刚换图之后 **300 s** 宽限；恢复了自动解除；断线时暂停计时 |

**区域与遥控（决策 65、66，对账 S7、R2）**

| 项 | 以前 | 现在 |
|---|---|---|
| 硬禁区 | 只有普通禁行区 | 禁行区可标 `hard`（水体、落差）；**遥控也守**：每拍按机身矩形（0.93 × 0.48 m）沿命令方向扫「一拍 + 延迟 + 刹车」，离硬禁区 σ + 5 cm 以内先减半、再四分之一、再只许原地转、再停；**往外、平行开永远允许**，已经压进去的只许让重叠面积不变大、中心不更深（开得出来）。普通禁行区遥控照旧不守 |
| 遥控时定位不可信 | 不管 | 图上有硬禁区时遥控限速 **0.2 m/s、0.4 rad/s** 并告诉操作员（不完全挡：丢定位时正要靠遥控开回能设位置的地方） |
| 区域确认（决策 66） | 任何改动都让确认作废 → 所有自主派遣（含入侵派遣、驱离）被拒，直到管理员重新确认 | 跟**最后确认过的那一份**比：只收紧（加或扩大禁行区、调低限速、加硬标记）→ 立即生效、记成编辑人确认、写审计；放宽或混合 → 照旧要管理员确认。收紧用几何判（每个老区域要被某一个新区域整个盖住且不更松）；把一个区拆成两块算放宽（往保守那边） |
| 临时区 | 没有到期 | 可设 `until_ms`；**站点按自己的钟**每 10 s 删过期的并推给狗；狗不自己过期（狗钟可能不准）。到期算放宽，只有「含它的那一份确认过」才算预先确认 |
| S7 每拍禁行区检查 | 机身**中心**离禁行区 ≤ 0.25 m 就停 | 三档：机身真压进去 → FAILED + P1（同以前）；刹车扫过区离 σ + 2 cm 以内且不是在离开 → 刹车、原地重规划，重规划用完才 FAILED（不报 P1）；正常靠近 → 降速保证刹车后留 σ + 10 cm。低于前进死区的限速区在回退检查、保持距离、起步挪动里都当禁行（以前只有规划这么算） |
| R2 新版本地图 | 区域从空开始，确认一张空表就放行 | 第一次打开没画过的新版本时，把上一版的区域（未过期的）、待命点、拦截点抄成**提议**（不生效、不发狗）；手机上横幅「从第 X 版带过来，坐标可能不对」，`frames.json` 不同再加一行红字；管理员逐项勾选后确认才生效（拦截点照样过可达性检查）；空表确认要额外一道提示（站点要 `empty_ok`） |

**路线与旁路（对账 R1、S11）**

| 项 | 以前 | 现在 |
|---|---|---|
| R1 巡检绑地图版本 | 任务只带 `map_id`；站点把**狗自己的版本**填进命令，狗端核对永远通过（`docs/任务包格式.md` 的说法跟代码不符） | 任务必须带 `map_version`；站点手动派、排程都按任务的版本跟狗加载的比，不一样不派（排程挑别的狗，没有就 `no_robot` 告警）；命令里发任务的版本，狗三方核（任务、命令、已加载）；没绑版本的任务不派。**老任务包导入时拒**（列出这张图现有的版本，不替人猜）；升级前已在库里的老任务读得出来、不派 |
| S11 旁路只收代理的运动命令 | 本机 `127.0.0.1:8090` 和 FIFO 谁都能发 `vel`/`walk` | 旁路每次启动生成 256 位口令写 `--token-file`（默认 `~/.d1max/sidecar.token`，0600，写临时文件再改名）；每个连接先 `auth`，没认证的运动命令回 `not_authorized`。**`halt`、按急停谁发都收**（停车永远不被挡）；松急停要口令；`clear`（净空许可）不要口令（只放行已认证的前进）；遥测照发。FIFO 只有属主是旁路账号、组和其他人不能写时才全收，否则只收停车类 |
| 老命令行厂家导航 | `d1max goto/walk` 直接走厂家导航（没有禁行区） | 默认拒，提示用站点的 goto；要 `--allow-vendor-nav` 才跑（现场执行单 7.1/7.8/7.9、现场手册 E2/E3 要用它核厂家导航本身） |

### 5.1 改了什么、行为变化
