# 商业化 A2 · 备份恢复与灾备演练 · 设计与完工报告

> 商业化 A 阶段第一单（决策 53：第一个客户的交付时间还没定，A 阶段按顺序做；HA 先热备，放 C 阶段，A 阶段先把备份恢复做扎实）。操作手册是 `docs/备份恢复与灾备演练.md`。

## 摸底时发现的最大缺口

以前的备份**没有站点身份**：没有 `site.json`，也没有 `ca/`（CA 私钥、站点服务证书）。站点主机坏了，就算备份全在，新主机也只能重新 `init`，结果是：

- 新的 CA、新的站点证书；
- **每只狗都要重新登记**；
- **每部手机都要重新添加站点**。

这是灾备上最大的一个洞。

## 做了什么

1. **站点身份进备份**：
   - `site.json` 每次备份都封进 `config/`；
   - `ca/`、`broker/` 走增量镜像。
   - **只进加密的备份**：明文备份盘被拿走，CA 私钥就丢了。没配备份密钥时记错误日志。装机脚本会生成备份密钥，正常不会走到这一步。
2. **校验**（`d1max_site.restore.verify`，命令 `backup-verify`）：
   - 最新库快照解得开、`PRAGMA integrity_check` 过；
   - 站点身份齐（`site.json`、CA 私钥和证书、站点服务证书和私钥）；
   - 库里登记的每一趟，备份里都有它的目录；
   - 每个加密文件**只核 MAC、不解密、不落明文**（新加的 `SealBox.verify_file`）。
3. **每周自动抽查**：
   - 前三项全做，文件抽 200 个；
   - 结果记库，值守汇总带上；
   - 没过报 P2 `backup_verify_failed`，过了自动解决；
   - 全量校验用命令。
4. **一条命令恢复**（`restore`）：
   - 只往空目录里放；
   - 库快照、身份、证据、地图、录包、升级包、broker 配置各回各位，CA 私钥权限 0600；
   - 恢复完自己校验一遍（`verify_home`）。
5. **灾备演练**（`backup-drill`）：
   - 恢复到临时目录、校验、跟正在跑的站点对数（只给人看，不算失败），然后删掉；
   - 结果记库，值守汇总带上。

## 测试

端到端：真的 `init` 一个站点、登记一只狗、收一趟证据、加密备份，然后：

- 备份里有站点身份，全是密文，CA 私钥看不到明文；
- 全量校验过；
- 改一个字节、没给密钥、不是这把密钥、缺 CA 私钥、缺一趟的目录，都查得出；
- **恢复**：一条命令恢复到新目录，**站点证书指纹不变**，库完整，照片一字节不差，CA 私钥权限 0600；
- 恢复只往空目录里放；
- 演练：恢复、校验、对数，记一笔；拿错密钥演练不过；
- 每周抽查：缺了 `site.json` 报 P2，一周只跑一次；下一次备份补上后，抽查过了、告警自动解决；
- 明文备份不放 CA。

**突变**：9 条全抓住：
- 身份不进备份、不核 MAC、不查 CA、不查每一趟；
- 恢复不还原 CA、恢复盖掉已有的站点；
- 抽查不报警、抽查天天跑；
- 明文备份也放 CA。

## 已知限制

- 连续录像不在备份里（太大）。站点主机坏了，录像就没了。要留就得配单独的录像存储（C 阶段对象存储）。
- 最多丢最后一个小时的改动（每小时备份一次）。要更少，就得上热备（C 阶段，决策 53）。
- 三把密钥靠人离线保管。演练时顺便核对；以后可以考虑分片或托管（A3 密钥管理时再看）。
- 恢复到新主机后，主机名或 IP 变了，要改狗上的站点地址。证书里写的主机名也要还在，不然得重签站点证书（`init` 时给多个 `--hostname` 可以预留）。

| R4 | 先记校验时刻、再报告警：告警写失败，一周内不再试 | 扫描结果和时刻同一个事务落库；**告警每拍按记下的结果对账**：没过、告警没开就报；过了、告警还开着就解决；失败了下一拍再来。站点重启照样从记下的结果对账。 |

**新增测试**（照外审的复现写，断言对的行为）：
- 删掉一张登记了的照片：校验、恢复都不过；
- 删掉整个 MQTT 配置：都不过；
- 明文备份不带站点身份：不过；
- 做到一半断了的那次不算，用上一次做完了的；老备份没清单不过；
- `umask 022` 下恢复：所有文件、目录都不给组和其他人权限（狗私钥也是）；明文备份恢复也不抄源文件的宽权限；
- 报 P2 写失败了，下一拍补上；自动解决失败了也补；扫描还是一周一次；
- 装机脚本恢复模式：密钥没放回就停、先查密钥再走到生成那一步、不 init、只启用不起服务（静态核对：这台机器上不跑系统级装机脚本）。

**突变**：8 条全抓住。「抄源文件权限」第一轮没抓住（只测了加密备份），补了明文备份的权限测试才抓住。
