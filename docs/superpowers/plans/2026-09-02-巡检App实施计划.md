# 巡检 App 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把建图、标点、编任务、跑任务、判读、出报告六件事收进一个浏览器页面，且整条链路无真机可测。

**Architecture:** 三层。最底下是**任务引擎**（纯库，不认识 HTTP，主规范 §6）；中间是**地图桥**这条新的只读遥测线（协议 + rclpy 脚本 + 仿真器三件套，与已有的定位桥同规格）；最上面是 **app**（一个 Python 进程：asyncio 线程跑引擎，`ThreadingHTTPServer` 跑 HTTP，两者靠 `run_coroutine_threadsafe` 和已有的 `EventEmitter` 搭桥）。

**Tech Stack:** Python 3.10 / asyncio / 标准库 `http.server` / PyYAML / 原生 JS + Canvas（无构建步骤）/ ffmpeg（外部可执行文件）/ pytest + pytest-asyncio / ruff

**Spec:** `docs/superpowers/specs/2026-09-02-巡检App设计.md`，其上游是 `docs/superpowers/specs/2026-08-31-d1max-patrol-inspection-design.md`（下称**主规范**）

## Global Constraints

- **不新增第三方运行时依赖。** app 只用标准库 + 已有的 `websockets` / `PyYAML`。判读那一步允许 `urllib` 直接打 Anthropic HTTP 接口，不引 `anthropic` SDK。
- **前端不引任何在线资源。** 无 CDN、无 npm、无构建步骤。`git pull` 完就能跑。
- 中文注释与 docstring。**`.py` 里的中文散文用半角逗号 `,`**，`.md` 里用全角逗号 `，`。测试函数名用中文。
- 待真机验证的推断，一律写成 `# 假设(待真机验证):` 开头的注释。
- ruff：`select = ["E","F","I","UP","B","BLE","RUF100"]`，`line-length = 100`。验收命令是仓库根目录下的裸 `python -m ruff check`。
- pytest：`asyncio_mode = "auto"`，**不要写 `@pytest.mark.asyncio`**。`pyproject.toml` 里已有 `addopts = "-q"`，跑测试用 `python -m pytest --tb=short`，不再叠 `-q`。
- **禁止删除或跳过任何已有测试。** 全量套件当前是 714 passed / 7 skipped，每个任务结束时这个数只能涨。
- 引擎层（`src/d1max_patrol/engine/`、`src/d1max_patrol/inspect/`）**不得 import `http` / `socketserver` / `app`**。有一条测试专门断言这件事（Task 12）。
- 任何"不支持"必须**显式拒绝**（抛异常 / 返回 4xx），不得静默无操作。这是本仓库的既有契约（见 `tests/contract/README.md`）。
- Windows 上开发、Ubuntu 上跑。凡是只在 Linux 成立的（`/proc`、进程组、`setsid`），测试要用 `pytest.mark.skipif(sys.platform == "win32", ...)` 圈起来，并在 skip 理由里写清楚。

```python
def _atomic_write(path: Path, text: str) -> None:
    """写临时文件再 os.replace。

    state.json 是崩溃恢复的唯一依据,而它每次状态迁移都被重写。就地覆盖的话,
    断电正好断在中间就留下半个 JSON —— 恢复的时候读不出来,等于没有恢复。
    os.replace 在同一文件系统上是原子的:读的人要么看见旧的,要么看见新的。
    """
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, path)
```
- `read_events` 跳过空行；**遇到坏行不静默丢**，抛 `ValueError` 并带上行号。

  ```python
  class RunState(str, Enum):
      IDLE = "IDLE"; PREFLIGHT = "PREFLIGHT"; LOCALIZING = "LOCALIZING"
      RUNNING = "RUNNING"; PAUSED = "PAUSED"; RETURNING = "RETURNING"
      ABORTING = "ABORTING"; ABORTED = "ABORTED"; DONE = "DONE"

  @dataclass(frozen=True, slots=True)
  class RunSnapshot:
      state: RunState
      mission: str
      waypoint_index: int
      waypoint_name: str
      total: int
      started_ms: int
      results: tuple[WaypointResult, ...]

  @dataclass(frozen=True, slots=True)
  class WaypointResult:
      name: str
      ok: bool
      arrived_ms: int
      elapsed_s: float
      photos: tuple[str, ...]
      note: str = ""

  class MissionEngine(EventEmitter[RunSnapshot]):
      def __init__(self, nav, device, media, runs_root: Path,
                   *, clock: Callable[[], float] = time.monotonic): ...
      @property
      def snapshot(self) -> RunSnapshot: ...
      @property
      def archive(self) -> RunArchive | None: ...
      async def start(self, mission: Mission) -> None: ...   # 已在跑 -> EngineBusy
      async def pause(self) -> None: ...
      async def resume(self) -> None: ...
      async def abort(self, reason: str) -> None: ...
      async def wait_done(self, timeout_s: float | None = None) -> RunState: ...

  class EngineBusy(RuntimeError): ...
  ```

**设计约束（主规范 §6.3）**：单一 asyncio 队列，状态机是唯一消费者。所有输入——后端事件、用户命令、定时器——都进这个队列。**因此测试可以直接往队列里灌事件序列并断言迁移**，不需要真后端。
