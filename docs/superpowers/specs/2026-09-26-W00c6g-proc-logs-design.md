# W00c6g 建图进程日志 · 设计稿

> 状态：**按推荐**（用户 2026-09-26「全部采纳，A，B，C和几项能力回复的全做了」；决策 9，P1）。
> 来源：W00c5e 退役的老服务 `GET /api/procs/<name>/log`（子进程日志的尾巴）。

## 问题

录包、重建（W00c5d 第二部分）在狗上起子进程（ROS 录包、隔离域里 slam_toolbox 离线重建、存图），每个进程的输出落在狗上的日志
文件里（`ProcManager.log_path`）。老服务能在页面上看这些日志的尾巴；W00c5e 删了老服务，现在录包、重建失败时站点只收到一句
「退出码 N，日志见 ……」，要看原因只能 SSH 上狗。

## 决定（都按推荐）

1. **狗上新命令 `proc_log`**（不是任务，只读）：
   - `{}` → 回执 `data` 里是有哪些日志：`{"logs": [{"name", "size", "mtime_ms"}]}`（按修改时间倒序，最多 50 个）；
   - `{"name", "bytes"?}` → 那个日志的**尾巴**：`{"name", "size", "bytes", "truncated", "text"}`，默认 64 KiB，最多 **128 KiB**
     （建图跑一小时日志几十兆，只给尾巴；老服务也是这么做的）；按 UTF-8 解、坏字节替换；从行首截（丢掉被截断的半行）。
     **实现时改的**：原来写最多 256 KiB —— 回执走 MQTT，站点 broker 单包上限就是 256 KB（`max_packet_size`，超了狗被断开），
     装不下；而且带颜色的日志里控制字符在 JSON 里一个字节变六个，所以尾巴**按编码之后的大小再裁到 160 KiB 以内**。
   - 名字只许 `[a-z0-9_.-]{1,48}`、只在日志目录里找，不许路径穿越，**链接一律当没有**；没有这个日志回 `no_such_log`。
   - **不进幂等记录**（实现时加的）：回执带着上百 KB 的日志，记下来代理起来要全量重放；重投的再查一次就是。
   - A（推荐）：回执带数据（W00c6d 起就有 `Ack.data`）。B：狗把日志当文件经发件箱传到站点。——日志是诊断用的、按需看，传一份要
     等上传、还要站点存；决策 8 是业务数据不落狗，日志不是业务数据。
2. **站点接口**：`GET /api/robots/<id>/logs`（列）、`GET /api/robots/<id>/logs/<name>?bytes=`（尾巴），**管理员**（`manage`：日志里有路径、
   参数，跟录包、重建同一级）。站点不存日志，现取现给。**这条回执不推给站点事件流（SSE）**（实现时加的：事件流谁登录了都
   收得到，保安、业主也是；手机收到每一帧都刷新狗的列表）。
3. **手机**：单狗页给管理员一个「建图日志」→ 日志列表 → 点开看尾巴（等宽字、可以滚、有刷新）。

## 不做

- 实时跟随（tail -f）：点刷新再取一次就够。
- 代理自己的日志（journald）：不在这一单，照旧 SSH 或以后单开。

## 测试

- 代理：列日志（倒序、只列日志目录里的）；取尾巴（默认、指定、上限、截到行首、坏字节）；满是控制字符的日志回执编码后也装得进一个包；
  名字不像话、穿越、链接、没有这个日志都拒；不进幂等记录；没有录包能力（没有日志目录）的狗不报这项能力；日志目录从进程管理器经编排报到。
- 站点：管理员能看、保安 403；转成命令、回执里的数据原样给；狗拒了 404/409；老代理 409；真狗端到端、事件流里不推。
- 手机：管理员有入口、别人没有；列表 → 尾巴；两页都能刷新；没有日志、取不到说清楚；横屏不溢出。
