## 问题

老服务建图是在线跑 2D slam_toolbox，建图桥一帧帧推「正在长的那张图」，人一边开一边看哪儿还没扫到。W00c5d 改成「录包 → 在狗上离线
重建 → 传到站点登记」之后：录包时手机上什么都看不到（不知道哪儿走过了）；重建完了，手机上也只有地图目录里的一行字，看不到图长什么样。

## 决定（都按推荐）

1. **不恢复在线实时栅格**：那要在录包的同时在线跑 2D 建图 —— W08 决定 4 已定「2D slam_toolbox 那一路不再往下走」（户外靠点云匹配 +
   RTK，离线出图归站点工具），在 Orin 上跟录包抢算力，而且过渡期的里程本来就漂（9 m 漂 2 m）。替代的是下面两样，覆盖「建图时看得见」
   的两个实际用处：**哪儿走过了**、**建出来的图对不对**。
   - A（推荐）：轨迹 + 建好的图的预览。B：录包时在线跑 slam_toolbox 推栅格。——跟 W08 冲突、吃算力、W09 之后要拆。C：只做预览。
     ——录包时还是两眼一抹黑。
2. **录包时的轨迹**：狗在录包期间按里程记一条轨迹（每挪 0.3 m 或转 15° 记一点，最多 5000 点，录包开始时清空；坐标是录包起点为原点的
   里程系 —— 新地方还没有地图、也没锚）。新命令 `mapping_trail {since?}`（只读，回执 `data` 带点列；`since` 是上次拿到的点数，只回
   新增的）。站点 `GET /api/robots/<id>/mapping/trail?since=`（管理员），手机录包期间每 2 s 取一次、画在录包页上（按比例缩放、标起点与
   当前位置）。
   - **实现时定的**：点满 5000 不再记、回执报 `full`（不抽稀：抽稀会让手机手上的 `since` 对不上）；回执还带 `recording`（手机据此
     停止轮询）、`total`（比手机手上的少 = 狗上重新开录了，手机从头取）；里程读不到或不新鲜的那一拍不记；这条命令同 `proc_log`
     只读、不进幂等记录、回执不推事件流（每 2 s 一条，不然所有手机每 2 s 刷一次狗的列表）；手机上「开始录包」收下了就打开轨迹页。
   - **内审之后**：开录成功当场清空、换 `epoch`，回执带 `epoch`、`starting`（录包还没起来）、`jumps`；手机按 `epoch` 判断换了一趟，
     `starting` 时接着问，切后台不问；NaN 里程不记，里程跳了轨迹接上。
3. **建好的图的预览**：站点把登记了的图（`.pgm` + `.yaml`）渲染成 PNG（未知灰、占据黑、空闲白，按分辨率标尺；最大边 1024 px），
   `GET /api/maps/<id>/<version>/preview.png`（查看权限）；手机地图页每一行点开看图（能缩放），同时画上这张图上登记的待命点。
   - **实现时定的**：站点主机上没有 PIL，纯 Python 解 PGM（P5/P2）、编 PNG；颜色照 `map_server` 三值；大图按整数倍缩，**一格里有占据
     就算占据**（细墙不丢），其次空闲、再其次未知。另加 `GET /api/maps/<id>/<version>/preview`（查看权限）给坐标换算与待命点：
     `{width, height, m_per_px, left_x, top_y, standby: [{robot_id, name, x, y, yaw, default}]}`，地图 (x, y) 在图上是
     `((x − left_x) / m_per_px, (top_y − y) / m_per_px)`（「按分辨率标尺」由手机按 `m_per_px` 写）。同一版渲染一次、缓存最近 8 张。
     没有栅格（比如点云图）404，文件坏了 500 说是哪个文件。
   - **内审之后**：先看文件大小再读（P5 按头算、P2 最多 8 MiB、yaml 最多 64 KB、最多 2500 万像素），渲染一次一张；预览 JSON 多带
     `source`（用的哪份 yaml）、`warning`（origin 带转角）。
4. 录包、重建的状态照旧走事件（`mapping_started`/`mapping_stopped`/`map_built`/`map_build_failed`），不变。

## 测试

- 代理：录包开始清空轨迹；按距离/转角抽稀；以起点为原点（带转角）；上限；`since` 只回新增；没在录包时回空、停了不再记；里程不新鲜
  不记；`since` 不像话拒；不进幂等记录；没有录包能力的狗不报这项。
- 站点：轨迹接口（管理员、转成命令、`since` 不像话 400、老代理 409、真代理端到端、不推事件流）；预览 PNG（尺寸、颜色映射、反色、
  文本 PGM、大图缩小细墙不丢、坐标换算、没有这张图 404、没有栅格 404、坏的 pgm 500 说清楚、只渲染一次）；查看权限；待命点只给这一版的。
- 手机：录包时轮询轨迹、只要新增的、画出来；停了不再轮询、刷新再看；狗上重新开录从头取；退出页面不再取；开始录包收下就打开轨迹页；
  地图页点开预览、画待命点（坐标换算）；没有栅格说清楚；横屏不溢出。
