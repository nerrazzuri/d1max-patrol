# W00c5c · 遥控经站点 —— 设计稿

日期：2026-09-25 · 工单：W00c5c（L，依赖 W00c5b）
状态：**按推荐（用户 2026-09-25 授权连续推进：「从W00c5a到W00c5e直接做完」）**。六个决定都取推荐项。**受决策 7 约束（用户批准、外审正式批准）**，其全部条件逐条落在下面，§7 有一张对照表。

## 0. 事实

- **决策 7 定稿**：「允许站点转发经过认证、持有控制租约的人类实时操作输入；禁止站点自主生成、重放或在操作者断线后延续运动指令。」
  - 外审条件：站点只转发（不生成、不补帧、不录制重放、不在断线后延续）；任一段断开，狗都由 TTL/看门狗自停；每帧带单调序号、产生时间与很短的 TTL，过期帧不执行；同一时间只有一个控制租约；任务与人工接管先停车再移交；急停与 halt 不走普通遥控队列；审计记操作者、机器人、租约起止与接管原因；不暴露底层 SDK 命令。
  - 另加三条：规矩由代理执行；人工遥控优先于所有自动任务；遥控限速先按自动导航上限的一半。
- **现在的遥控**：手机直连狗，HTTP 每 300 ms 一拍定时行走 + 200 ms 心跳，0.6 s 没心跳就停；「没画面不许动」。**经代理托管时跑不通**：闸门拿到的视频表是空的，设备桥也不做定时行走。
- W00d 已有**带有效期的持续速度**（`vel`，HAL 的 `set_velocity(VelocityCommand(ttl))`），旁路进程的运动安全门已过外审。
- W00c5b 已有站点的**画面健康**（`video/health`）；狗上推流器知道自己有没有在推。
- 站点 API 是标准库 `http.server`，没有 WebSocket；手机端 `dart:io` 有 `WebSocket`（可以带钉证书的 `HttpClient`）。
- 站点到狗只有 MQTT：`cmd`（QoS 1，持久会话会补投）与狗的上行。

## 1. 决定一：手机到站点怎么走

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | **一条 WebSocket**（`wss://站点/api/robots/<id>/teleop`，钉证书、令牌鉴权），站点用标准库实现最小的服务端（握手、带掩码的数据帧、ping/close）。**连接就是租约的载体**：连着 = 在控制，断了 = 立刻放（站点当场发停车并放租约）。手机按住摇杆时每 100 ms 发一帧 `{seq, vx, wz}`，松手发零速；站点每 1 s ping，3 s 没回应就当断了 |
| B | 每帧一个 HTTPS POST。断没断只能靠「帧不来了」猜，租约和连接对不上 |

## 2. 决定二：站点到狗怎么走

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | **帧走专用主题 `…/teleop`，QoS 0、不保留**（契约加这个主题：站点写、狗只读自己的；broker ACL 同一张表生成）——**绝不经 `cmd`**：`cmd` 是 QoS 1 持久会话，断线重连会**补投旧帧**，那正是决策 7 禁止的「重放」。**租约与停车走 `cmd`**：`teleop_lease`（授予/续期/收回，带租约代次、操作者、有效期）与 `halt`（插队的停车，不是任务） |
| B | 帧也走 `cmd`。持久会话补投旧摇杆值，违反决策 7 |

## 3. 决定三：狗怎么判一帧能不能执行（规矩由代理执行）

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 每帧带：`lease_epoch`、`seq`（站点从 1 起单调加）、`sent_at`（站点发出时刻，站点的钟）、`ttl_ms`（300）。代理只执行：**租约代次等于当前有效租约**、**seq 严格大于上一帧**、**在途时间不超标**。狗与站点的钟不必对准：代理记 `到达时刻(狗钟) − sent_at(站点钟)` 的滑动最小值当基线，一帧比基线多出 `MAX_TRANSIT_MS`（250）就算在途积压、丢掉。执行 = `set_velocity(ttl=帧的 ttl)`；**帧不来了，TTL 到了狗自己停**（HAL 与旁路进程两层）。不合规的帧一律丢、计数、不回执 |
| B | 直接比狗钟与站点钟。狗的钟现场就错过（Orin 那次） |

## 4. 决定四：狗上怎么跑、跟自动任务怎么让

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 遥控是一种**任务**（`teleop`），优先级 **100**（高于事件 80）：租约授予时它**抢占**正在跑的自动任务——先停车、等停稳（`stopped()`），再开始收帧（「先停车再移交」）；遥控期间派来的自动任务一律回 `busy`，站点派单时也把遥控中的狗挑开（事件派遣会去找别的狗）。**限速**：遥控的速度上限 = HAL 能力的一半（`max_vx/2`、`max_wz/2`），代理夹，站点也夹。**没画面不许动**：站点授予租约前与转发每一帧时查 `video/health` 至少一路在线（不在线就发零速、不转发）；代理这头再查自己的推流器至少一路在推（独立的第二道）。租约有效期 5 s，站点在连接活着时每 1 s 续；代理这头租约到期 = 任务结束（停车） |
| B | 遥控在任务调度之外单开一个模式。跟自动任务抢 HAL，谁先停谁后动说不清 |

## 5. 决定五：租约、接管与审计

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 站点每台狗**至多一个遥控租约**：新权限 `teleop`（管理员、保安；业主没有）。有人握着时别人来开回 409 并说是谁；**管理员可以强制接管**，必须写理由：旧连接收到「被接管」后关掉，狗先停车（旧租约收回），再授予新租约（代次加一）。审计记：谁、哪台狗、租约开始与结束时刻、结束原因（自己放、断线、被接管、狗掉线、画面没了、halt）、接管理由。**不记每一帧摇杆值** |
| B | 可配置的多级接管、排队。一个庄园用不上 |

## 6. 决定六：急停与 halt

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | **halt 不走遥控连接**：`POST /api/robots/<id>/halt`（`abort` 权限，业主也能按）→ `cmd` 上一条 `halt`（不是任务、插队）→ 代理当场 `hal.stop()`、结束遥控任务与当前任何任务。手机遥控页的大红「停」按钮走这一条，**同时**在 WebSocket 上发零速。软急停不在这一张（仍由机身硬急停与现有路径负责），列进待办 |
| B | halt 也塞进遥控帧。连接卡住的时候正是最需要停车的时候 |

## 7. 决策 7 条件对照

| 条件 | 落在哪 |
|---|---|
| 站点只转发，不生成、补帧、录制重放、断线后延续 | 站点只把收到的那一帧加上 `lease_epoch/seq/sent_at` 原样转出；不缓存、不插值；连接断了立刻停转发并发 `halt` + 收回租约 |
| 任一段断开狗都自停 | 手机↔站点断：站点发停车；站点↔狗断：帧不来了，300 ms TTL 到了 HAL/旁路进程自停；租约 5 s 到期任务结束 |
| 每帧单调序号、产生时间、很短 TTL，过期不执行 | §3：代理查 `seq`、在途时间、`ttl_ms=300` |
| 同一时间一个租约 | §5：站点至多一个；代理只认当前代次 |
| 任务与人工接管先停车再移交 | §4：抢占时先停稳再收帧；租约结束先停车 |
| 急停与 halt 不走遥控队列 | §6 |
| 审计 | §5 |
| 不暴露底层 SDK 命令 | 帧只有 `vx/wz`，经 HAL 的 `set_velocity`；没有任何透传 |
| 规矩由代理执行 | §3、§4：代次、seq、在途时间、限速、没推流不动都在代理这头再查一遍 |
| 人工遥控优先于所有自动任务 | §4：优先级 100、自动任务回 busy、事件派遣挑开 |
| 遥控限速减半 | §4 |

## 8. 形状

- 契约：主题 `teleop`（站点写、狗读）；`TeleopFrame`（`lease_epoch, seq, sent_at, ttl_ms, vx, wz`，校验范围）；命令 `teleop_lease`（`{lease_epoch, operator, ttl_ms, action: grant|renew|release}`）与 `halt`；任务种类 `teleop` 的资源与断线策略（断线 = 停车、不续）；夹具。
- 代理：`tasks/teleop.py`（优先级 100 的任务：先停稳再收帧、按帧 `set_velocity`、限速一半、没推流不动、租约到期结束）；`teleop_frames.py`（帧的判定：代次、seq、在途基线）；`commands.py` 接 `teleop_lease`、`halt`；运行时订 `teleop` 主题。
- 站点：`ws.py`（最小 WebSocket）；`teleop.py`（租约表、转发、画面门、接管、续租、断线收尾、审计）；API：`GET /api/robots/<id>/teleop`（升级成 WebSocket，`teleop` 权限）、`POST /api/robots/<id>/halt`（`abort`）；派遣器把遥控中的狗算作不可派；broker ACL 加 `teleop`。
- 手机：站点单狗页「遥控」（保安、管理员）→ 遥控页：画面（`SiteVideo`）+ 摇杆（复用 `widget/joystick.dart`）+ 租约状态 + 大红「停」（走 halt）。按住每 100 ms 一帧，松手零速；连接断了屏上立刻说、摇杆变灰。
- 直连模式的遥控**这一张不删**（W00c5e 一起退役）。

## 9. 验收

- 仿真端到端（真 WebSocket、真 MQTT 内存 broker、仿真狗）：保安连上 → 拿到租约 → 推摇杆狗动（速度不超过上限一半）→ 松手停 → 断开连接后 300 ms 量级内狗停、租约收回、审计有一行。
- 旧帧（seq 不增）、别的代次的帧、在途积压的帧都不执行；站点↔狗断开（模拟）狗在 TTL 内停。
- 狗在跑巡检时授予租约：巡检被抢占、先停稳；遥控期间派巡检回 busy、事件派遣挑开这台狗。
- 画面没有：不给租约；遥控中画面断了：站点停转发、狗停。
- 第二个保安来：409；管理员带理由接管：旧连接被关、狗先停、新代次、审计记理由。
- halt：业主也能按；走 `cmd` 不走遥控连接；狗停、遥控任务结束。
- 手机（Dart）：遥控页按角色出现；按住发帧、松手零速；断线提示；「停」走 halt。
- 真机项（3c）：摇杆到狗动的延迟、4G 上抖动时的表现、限速一半是否够用。
