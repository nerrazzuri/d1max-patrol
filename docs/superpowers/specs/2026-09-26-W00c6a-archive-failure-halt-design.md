# W00c6a 写盘失败不卡死、叫停停得住 · 设计稿

> 状态：**按推荐**（用户 2026-09-26「全部采纳，A，B，C和几项能力回复的全做了，做完了就写报告，我让外审再查一下」；
> 决策 10，P0：真机运动之前必须修）。来源：核查 W01–W07 外审分析时新发现的 B。

## 问题（仿真实测过）

1. **巡检途中归档写不进去，引擎任务死掉、快照停在 RUNNING。** `RunArchive` 的每一处写（照片、事件流、
   `state.json`、`manifest.json`）都不接 `OSError`。第一张照片存不下 → 兜底 `_do_abort` 第一步
   `_transition(ABORTING)` 又要写事件流、又抛 → `_finish` 里 `archive.finish` 再抛 → `_done.set()` 走不到。
   引擎任务带着 `OSError` 结束，对外快照一直是 RUNNING；代理的巡检任务按快照判终态，永远在跑，站点一直看到
   狗忙，只能重启代理。盘满、eMMC 出错后只读重挂（ext4 `errors=remount-ro`）都会触发。
2. **这时候叫停停不住。** 叫停只做一次 `hal.stop()`，然后指望引擎去停导航；引擎已经死了，导航桥
   `HalNavBackend` 还在 ACTIVE，下一拍又发速度（仿真：叫停后 5 秒狗从 1.3 m 走到 5.7 m，0.8 m/s）。回执照样
   是「收下」，手机上显示停了。
3. `storage.py` 自己写着「已经在跑的那一趟不因为盘满而停，半趟数据比空盘值钱」，代码没做到。

## 决定（都按推荐）

1. **归档写失败不往引擎外抛。**
   - A（推荐）：事件流、遥测流写失败 → 这一趟这一条流停写（不交错写出半行），记下第一条错误；`state.json`、
     `manifest.json` 是原子写（临时文件 + 换名），失败记错误、下一次照试（不会留半个文件）。
   - B：写失败就中止整趟。——盘满时狗原地趴下，跟「半趟数据比空盘值钱」相反；而且中止本身也要写。
   - C：照旧抛，只在引擎收尾兜住。——兜底路径本身就要写，兜不住（这次的问题就是它）。
2. **照片存不下 → 这个点按失败算**（`_FailWaypoint("照片存不下：…")`，走任务包的点位失败策略：重试、跳过或
   中止），不整趟中止；写了半截的照片文件删掉。巡逻本身（在场、画面经站点推流）照样有价值。
3. **引擎收尾一定走完。** `_finish` 用 `try/finally`，`_done.set()` 和拆后台任务放在 `finally`；收尾时
   状态还不是终态（兜底路径自己炸了）就先停导航、把状态落成 `ABORTED` 再广播。`_do_abort` 的停导航放进
   `finally`：前面记状态出什么事，导航都要停。
4. **叫停不依赖引擎。** 叫停的两条路（抢先的 `_halt_now`、排队的 `_handle_halt`）都先撤导航桥的目标
   （`nav.stop()`，桥进 Cancelled、不再发速度），再 `hal.stop()`。引擎活着时它会收到 Cancelled 和随后排进来的
   中止命令：重发下一个点之前要先等导航回 StandBy（终态驻留 0.5 s），这期间中止命令就被处理掉了，不会重走。
5. **代理看门。** 巡检/goto 任务每拍看：引擎任务已经结束、快照却不是终态 → 停导航、停 HAL，任务 `failed`
   （`engine_died: <异常>`）。有了 3 这条不该再走到，是最后一道。
6. **让人知道。** 代理在这一趟归档第一次写失败时发事件 `archive_write_failed {task_id, reason}`（一趟一条），
   站点出告警 `archive_failed`（P1：这一趟的照片、记录没存下，证据缺；多半是盘满或盘坏了，要人看）。

## 不做

- 只读重挂的根因（换盘、fsck）是现场的事；盘满的根因已有 `disk_80` / `storage_full`（W00c5d）。
- 写失败时自动回原点：中止不含位移（主规范 §6.4），回不回家由人定。

## 测试

- 引擎：第一张照片时盘满（之后所有写都失败）→ 引擎走完、状态是终态、`wait_done` 回得来、这个点失败理由写明
  「照片存不下」、导航停了；走到半路所有写都失败 → 照样走完；收尾路径自己抛 → 状态落成 ABORTED、`_done` 置上。
- 归档：事件流写失败之后停写、不抛；原子写失败不抛、不留临时文件；照片写失败删半截文件、照样抛给引擎。
- 代理：走到半路盘变只读、叫停 → 5 秒内不再走（仿真 HAL，把上面那次实测变成测试）；引擎任务死掉、快照还是
  RUNNING → 任务 `failed`、停导航与 HAL；归档写失败 → 一趟一条 `archive_write_failed`。
- 站点：`archive_write_failed` → `archive_failed` 告警（P1）。
