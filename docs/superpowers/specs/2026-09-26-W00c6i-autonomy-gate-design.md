# W00c6i 过渡期自主移动技术闸 · 设计稿

> 状态：**按推荐**（W08 决定 11；用户 2026-09-26「开，排在 W00c6 里一起做」，决策 11，P0：`D1MAX_HAL` 切到 `d1max`
> 之前做完）。

## 问题

W11 避障真机验收之前，真狗的自主移动是：直线、拿运控里程当地图、没有避障。口头规矩（真机移动要人在场）挡不住：
`D1MAX_HAL` 一改成 `d1max`，站点排程（W00c2a）、CCTV 事件派遣（W00c2c）、巡检后自动回待命点（W00c2b）都能在没人在场时
把真狗派出去。

## 决定（都按推荐）

1. **代理有一个自主级别**：`supervised`（要人监护）或 `autonomous`（可自主）。
   - `--hal d1max` 默认 `supervised`；`--hal sim` 默认 `autonomous`（仿真、测试、站点联调）。
   - 显式配置 `D1MAX_AUTONOMY=autonomous`（经 `deploy/d1max-agent-start` → `--autonomy`）才放开 —— **W11 真机验收过了、
     用户明确同意之后**才改；代理起来时把级别写进日志。
2. **能力里报级别**：`tasks.goto.autonomy`、`tasks.patrol.autonomy`。站点读不到按 `supervised` 算（保守）。
   - 与 W08 决定 11 原文「不报 `patrol`」的差别：有人监护的巡检是 W09–W11 真机调试要用的，所以照报 `patrol`，但带上级别；
     站点的自动派单只认 `autonomous`（决定 4），效果一样挡住无人时的排程。
3. **监护租约**（`supervised` 级别下）：
   - 手机上「我在现场监护」开着时，每 1 s 向站点发一次心跳（`POST /api/robots/<id>/supervise {"action": "renew"}`）；
     站点转成一条**有效期很短**（3 s）的 `supervise` 命令发给狗（`cmd` 主题，不是任务；过期的命令代理照规矩拒收 —— 断线
     重连补投的旧心跳续不上租约）。
   - 代理按**单调钟**记「监护到什么时候」（收到时刻 + `ttl_ms`，默认 3 s，范围 1–10 s）。
   - 关掉开关、离开页面、切后台 → 手机发 `{"action": "release"}`（尽力而为）；发不出去也会在 3 s 内过期。
   - 谁在监护记进命令的 `issued_by`（审计）；站点只许保安、管理员开监护（跟派单同一权限），业主不行。
4. **代理的闸**（`supervised` 级别下）：
   - 收 `goto`、`patrol` 时不在监护中 → 拒收（`unsupervised`）；遥控、叫停、换图、发布等不受影响（遥控另有决策 7 的规矩）。
   - 正在跑的 `goto`/`patrol` 监护过期 → 当场中止（`supervision_lost`），走停车确认；排队中的一起清掉。
   - `autonomous` 级别下不看监护（跟现在一样）。
5. **站点的派单**：排程（W00c2a）与事件派遣（W00c2c）只派给 `autonomous` 的狗；`supervised` 的狗排程记 `no_robot`
   （理由写「要人监护，不接排程」）、事件派遣跳过它。手动派单照发，由代理的闸决定收不收（回执说清为什么不收）。
   巡检后自动回待命点照发 —— 没人监护时代理拒收，站点推 `standby_failed`（现有路径）。
6. **手机**：单狗页上，对 `supervised` 的狗显示「我在现场监护」开关与说明（「开着的时候狗会执行下发的任务；关掉、离开这一页、
   切到后台就停」）；开着时每秒续一次、页面标红「监护中」；派单被拒（`unsupervised`）时说人话。

## 不做

- 监护租约不要求画面（遥控才要）；人在现场本身就是监护。
- 多个人同时监护同一条狗：任何一个人在续就算有人（租约是「有人在场」这件事，不是独占）。
- 自动把级别从 `supervised` 升到 `autonomous`：只由配置改，改之前要用户同意。

## 测试

- 代理：`d1max` 默认 `supervised`、`sim` 默认 `autonomous`、显式配置覆盖；能力里报级别；`supervised` 下没监护拒收 `goto`/`patrol`
  （回执 `unsupervised`），监护中收下、跑着的时候监护过期当场中止、狗停下；续租命令过期拒收；放租立刻生效；`autonomous` 下不看监护；
  遥控、叫停不受影响。
- 站点：心跳转成短有效期的 `supervise` 命令；权限（业主不行）；排程与事件派遣跳过 `supervised` 的狗（读不到按 `supervised`）。
- 部署：启动脚本把 `D1MAX_AUTONOMY` 传成 `--autonomy`。
- 手机：开关只对 `supervised` 的狗显示；开着每秒续、关掉或离开页面放租、切后台停；被拒说人话。
