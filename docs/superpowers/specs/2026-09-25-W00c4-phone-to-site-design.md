# W00c4 · 手机改连站点 —— 设计稿

日期：2026-09-25 · 工单：W00c4（L，依赖 W00c2c、W00c3）
状态：**按推荐（用户 2026-09-25 授权连续推进：「把整个 W00 跑完再给外审，都按你推荐的来」）**。三个决定都取推荐项。

## 0. 事实

- 手机端（Flutter，只做 Android）现在只会**直连狗**：连狗的热点、PIN 质询-应答（`net/patrol_client.dart`）、四个主屏（名册、遥控、控制权面板、盘况、值守）。老服务端 `server.py` 有 68 条路由。
- 站点现在有的：登录（账号口令、角色）、机器人列表与状态、派 goto/patrol、abort、回待命点、任务包与排程、外部事件账、审计、SSE。**站点没有的**：遥控（卡在待拍板第 7 条）、视频转发与录像、建图、狗上的存储与导出、发布包安装。
- 总设计 §1 硬规则 1：「手机与大屏永远不直连狗」。这是**目标**；遥控与视频没有站点通路之前，直连是唯一能遥控、看视频的路。
- 开发机原先没有 Flutter；W00c4 在任务目录里装了 Flutter 3.47.5（Dart 3.13.4，与 `pubspec.yaml` 的 `^3.13.2` 对得上），不动系统。

## 1. 决定一：这一张做到哪

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 手机加**站点模式**，覆盖站点现在能做的全部：登录站点、狗的列表与实时状态（SSE）、派巡检（选任务包里的任务）、abort、回待命点、事件账、排程。按角色显示按钮（业主只有「叫停」）。**直连狗的几屏（遥控、视频、盘况、控制权）原样保留，标「现场直连（过渡）」**，等遥控与视频有站点通路再撤。`server.py` 的退役与路由测试改写、`alerts/baselines` 搬家，另开 **W00c5**（依赖待拍板第 7 条与视频转发） |
| B | 这一张就把直连全撤掉。遥控、视频、盘况会整块没有 |

## 2. 决定二：手机怎么信任站点的 HTTPS

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | **钉站点服务证书的 SHA-256**：`d1max-site fingerprint` 打出来（`init` 时也打），添加站点时人照着填（或将来扫码）；手机只认这张证书，别的一律断开。证书重签（825 天）后重新核对一次 |
| B | 把站点 CA 装进 Android 的系统信任区。要用户去系统设置里装证书，现场做不下来 |
| C | 第一次连上就信（TOFU）。第一次正好被人截了就全完 |

## 4. 形状

- 站点：`d1max-site fingerprint`（打站点服务证书的 SHA-256）。
- 手机：`net/site_client.dart`（登录、令牌、钉证书、JSON 请求、SSE 读流、错误统一成 `SiteError`）；`model/site.dart`（站点、机器人视图、事件、排程）；`store/site_store.dart`（站点地址、证书指纹、账号名；**口令不落盘**，令牌只在内存）；`ui/site_page.dart`（登录、狗列表、单狗页：状态、派巡检、叫停、回待命点；事件页；排程页）；`main.dart` 首屏二选一：「站点」「现场直连（过渡）」。
- 夹具：站点的报文形状由 Python 侧生成 `mobile/test/fixtures/site_*.json`，Dart 侧读同一份（沿用「Python 夹具先红、Dart 跟着红」）。
- 测试：Dart 侧用 `dart:io` 起一个假站点（HTTPS 自签证书 + SSE），测登录、钉证书（对的连、错的断）、派单、403 显示、SSE 更新。

## 5. 验收

- 全仓不再有 `d1max_patrol.engine`；`src/d1max_patrol/engine/` 不存在。
