# W00c3 · 账号与角色 —— 设计稿

日期：2026-09-25 · 工单：W00c3（L，依赖 W00c1；W20 的前置）
状态：**按推荐（用户 2026-09-25 授权连续推进：「把整个 W00 跑完再给外审，都按你推荐的来」）**，决定一、三、四取推荐项。**决定二涉及已拍板的决策 5 与总设计 §3.5 的口径冲突，不代拍**：按推荐项 A 先不做遥控转发，冲突列给用户。

## 0. 事实

- W00c1 的站点只有一种账号（管理员），每条命令已绑定到登录的账号（`issued_by`）。
- 总设计 §5：`app/{auth,control,identity}` 去站点，「**已认证用户必须绑定到命令、租约、审计事件**——不再信任请求体里的 `user`」。
- 老 HTTP 面（狗上）有 PIN、会话、控制权租约（`app/control.py`）与审计（`/api/control/audit`），租约是给**遥控**用的：谁握着控制权谁能开狗。
- **口径冲突**：决策 5（2026-09-24 已确认）写的是「服务器可下发任务级指令，**不可遥控**」；总设计 §3.5 写的是「遥控路径：手机 → 站点 → 代理，独立低延迟 WebSocket」。站点转发人的遥控算不算「服务器遥控」，两处说法不一。

## 1. 决定一：角色

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 三个固定角色、一张固定权限表：**admin**（管理员：账号、狗的登记与吊销、任务包、事件源、拦截点、待命点，以及 guard 的一切）；**guard**（保安：派 goto/patrol、abort、回待命点、看一切）；**owner**（业主：看状态、看事件与排程、**abort**——业主看到狗在院子里乱走要能叫停）。站点 API 每条路由声明所需权限 |
| B | 可配置的 RBAC（自定义角色、权限点）。单个庄园用不上 |

## 2. 决定二：遥控转发（§3.5）

| 选项 | 内容 |
|---|---|
| **A（推荐，取；不代拍）** | **W00c3 不做遥控转发**。决策 5 与 §3.5 的冲突列进「待人拍板」给用户：若确认「站点转发人的遥控」不违反决策 5，遥控转发（WebSocket、租约、代理侧 `teleop` 任务与帧 `seq`/新鲜度校验）另开一张单 |
| B | 按 §3.5 现在就做 |

## 3. 决定三：审计

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | 只追加的 `audit` 表：登录成功/失败/锁定、注销、每一次**改动类** API 调用（谁、什么动作、对象、结果、时刻、来源地址）；`GET /api/audit`（admin）。派单本身已进 `commands` 表（带 `issued_by`），审计里再记一行指向它 |
| B | 再加哈希链防篡改。单站点、库在站点主机上，先不做 |

## 4. 决定四：账号管理

| 选项 | 内容 |
|---|---|
| **A（推荐，取）** | API（admin）与命令行：加账号（带角色）、改角色、停用/启用、重设口令；**停用或降级最后一个启用的 admin 拒绝**；停用/改角色/重设口令时**吊销这个账号的全部会话**。自己改自己的口令要旧口令 |
| B | 只做命令行 |

## 5. 形状

- `accounts.py`：`role` 列（已有）、`disabled` 列；`add(name, pw, role)`、`set_role`、`set_disabled`、`reset_password`、`change_password`；`check()` 返回 `(name, role)`，停用的账号令牌作废。
- `permissions.py`：权限表（`view`、`dispatch`、`abort`、`manage_robots`、`manage_accounts`、`manage_catalog`、`view_audit`）与角色的映射。
- `audit.py`：`audit` 表与写入；API 层在每条改动类路由上记。
- `api.py`：每条路由声明权限，没权限 403；`/api/accounts`（GET/POST）、`/api/accounts/<name>`（POST：role/disabled/password）、`/api/me/password`、`/api/audit`。
- CLI：`add-account NAME --role`、`set-role`、`disable`/`enable`。`add-admin` 保留（= `add-account --role admin`）。

## 6. 验收

- owner 派 goto → 403；owner abort → 200；guard 登记待命点 → 403；admin 一切可做。
- 停用账号后它的令牌立刻 401；最后一个 admin 不能被停用或降级。
- 审计里能看到：失败登录、派单（指向 command_id）、改角色、停用。
