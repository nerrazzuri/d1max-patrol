# 商业化 B2 · 手机 App V2 · 设计与完工报告

> B 阶段第二单。网页值班台（B1）是保安电脑上的主界面；手机 App 是第二界面，这一单把它改到跟值班台同一套规矩：
> - 英文为主，中文可选；
> - 专业版视觉（`docs/视觉规范.md`）；
> - 普通页面可以竖屏；
> - 扫码添加站点；
> - 告警页按规范 2.5 重排。
>
> 功能没有增减：原来能做的事都还在原来的页面上。

## 用户定的（沿用，不是这一单新拍的）

- 英文为主、中文可选；专业而不是漂亮；颜色只给报警。
- 普通页面竖屏、遥控横屏（决策 44，「全横屏留到 App V2 再改」）。
- 第一个客户先做安卓；鸿蒙是下一单的样品。

## 做了什么

### 中英文

- 写法：`tr('Stop all', '全部急停')`，两种文字并排写在用的地方（`mobile/lib/l10n.dart`）。
  - 带变量的两边各自插值。
  - 不需要界面上下文，网络层的报错文字也走它。
  - 代价：加第三种语言要改每一处。现在只定了两种。
- 全部 28 个文件、五百多条文字都改了。
- 第一次打开是英文。在站点列表右上角换语言，选了什么存在本机（`lang.json`），整个界面跟着换。
- 告警标题：英文界面按种类查词条（`design/i18n/alerts.json`，跟值班台同一份）；中文界面用站点给的原文。
- 画禁行区、限速区时存到站点的缺省名字是中文，英文界面显示时翻过来；人自己起的名字原样显示。
- 安卓的应用名：英文系统是 `D1 Max Patrol`，中文系统是 `D1 Max 巡检`。

### 专业版主题

- 颜色、字号、尺寸来自 `design/tokens.json`，用 `tools/gen_mobile_design.py` 生成 Dart 常量（`mobile/lib/design/*.g.dart`）。改了 JSON 忘了重新生成，测试会红。
- 主题在 `mobile/lib/ui/theme.dart`：中性深灰，按钮是灰白实底或描边，没有品牌色、阴影、水波纹。
- 字体：Atkinson Hyperlegible Next / Mono 打进包里（SIL OFL 1.1，许可证在 `assets/fonts/OFL.txt`，也登记进了 App 的许可证页）。中文用系统字体。
- 页面里写死的颜色都换成了色板：
  - 红只给 P1 和急停类按钮（红底、白字、报警框）；
  - 琥珀只给 P2 和要人知道的异常；
  - 布防 / 在家 / 访客、下雨、「正常」都不上色。
- 告警在列表里也是三重编码：颜色 + 形状（P1 菱形、P2 三角、P3 空心圆）+ 文字。

### 竖屏

- 普通页面不再锁方向：跟着手机的自动旋转设置，关了自动旋转就是竖屏。安卓清单从 `sensorLandscape` 改成 `fullUser`。
- 遥控页进来锁横屏，离开放开。
- 竖屏放不下的地方改了：
  - 顶栏的文字按钮（待命点、拦截点、事件页）收进「⋮」菜单；
  - 狗列表顶栏的五个入口（版本、地图、记录、事件、排程）收进菜单，带文字；
  - 值守屏告警卡片的「确认 / 解决」放到标题下面一行。
- 横屏、桌面版的摆法不变。

### 扫码添加站点

- 配对码是一行字：`D1MAXSITE1.<base64url(JSON)>`，里面只有站点名、手机要连的地址、站点证书指纹。**没有账号、口令、令牌**。
- 站点（`packages/site-node/src/d1max_site/pairing.py`）：
  - `GET /api/pairing?url=…`：登录了谁都能拿。地址由网页带过来，因为站点不知道自己在外面叫什么；
  - `d1max-site pair-code --url https://主机:端口 [--name 名字]`；
  - 地址只收 `https://主机[:端口]`，不带账号、路径、查询串。
- 值班台：Admin → System 页多了「Add this site to the phone app」，显示二维码、站点名、指纹和配对码，地址可以改（手机走 VPN 或另一个网段时）。
- 手机（`mobile/lib/ui/site_add.dart`、`site_scan.dart`、`net/pairing.dart`）：
  - 添加站点改成一整页：「扫码」「粘贴配对码」，下面是原来的四栏，也可以手填；
  - 扫到以后把站点名、地址、指纹填进表单，并提示人跟值班台上显示的核对；账号自己填；
  - 扫到狗的开通码或别的二维码会说清楚，表单不动；
  - 桌面版没有相机插件，没有「扫码」按钮，粘贴可用。
- 相机用 `mobile_scanner` 7.4.2（识别库打在包里，不依赖谷歌服务）。

### 告警页（视觉规范 2.5）

原来的「告警现场」页改成一页处理完一条告警（`mobile/lib/ui/site_alert_scene.dart`）：

- **报警头**：P1 红色实底，优先级、标题、时刻；下面一行是「没人确认已经 0:42」或「谁在几点确认了」。
- **报警框**：只有没确认的 P1 闪（1.6 秒一个来回），确认了就稳住。P2 不闪。
- **实时画面**：手机一次只拉一路，前后可切。
- **在哪**：防区名大字；下面一句是人离狗多远、驱离到第几级。驱离接口没拿到时写「说不清」，不当成没有。
- **四个大按钮**（52 高）：
  - 我来处理（确认）；
  - 开警笛（第 2 级）；没在驱离、又是狗看见人时，这个位置是「就地驱离」；
  - 误报（先问一遍，记了就关掉这条告警并回上一页）；
  - 对讲：还没有（灰的）。
- **现场细节**：防区、拦截点、狗最后在哪、那一趟；在图上看、现场录像、现场照片（跟原来一样）。
- **事件经过**：告警、驱离开始和升级、确认、关闭的时刻；最后一行琥珀色是「接下来多久自动升级」。
- **全部急停**：顶栏右边，红底加报警框。先问一遍，只对在线的狗发，哪台没停住说出来。只有能派遣的角色看得到。
- 每 3 秒左右向站点再问一遍：别人在别处确认了，这一页自己跟上。
- 横屏时报警块在左、其余在右。

## 测试

- 手机：444 条通过（原来 320 条）。**原有测试默认在中文下跑、一条文字断言没改**，证明中文界面一个字没变；只给 5 处点击补了「先滚到看得见」。
- 新加的：
  - 版面矩阵：24 页 × 竖屏 390×844 / 横屏 800×360 × 英文 / 中文，专业版主题下都不溢出；
  - 源码扫描：`lib/` 里的中文只许出现在 `tr()` 的第二个参数，英文那一半不许有中文和全角标点；7 处例外逐条写了原因；
  - 配对码：站点真出的码手机读得出来（中文站点名、IPv6 地址）；坏码、狗的开通码、形状不对的地址都不收；
  - 告警页：闪与不闪、确认前后、别人确认、驱离说不清、警笛、误报、业主没有警笛和全部急停、全部急停；
  - 语言切换与存盘、竖屏菜单、遥控锁横屏。
- 站点：配对码 41 条、设计常量 3 条。Python 全量结果见 PR。
- 网页：24 条通过，构建产物已更新。
- 安卓调试包能编过（含相机插件）。
- 出图工具 `mobile/test/shots_test.dart`（平时跳过）：用真字体把几页画成图，这一单用它看过竖屏的站点列表、添加站点、狗列表、单狗页、值守屏、告警页、布防模式、待命点。

## 没做的

- **真机没验**：相机扫码、相机权限提示、竖屏走查、字体在真机上的样子，都只在开发机上验过。
- **站点给的文字仍是中文**：告警的原因、狗拒绝的原因、体检明细。英文界面上会夹着中文（跟值班台一样）。要改得站点按种类给代码，另立一单。
- **语言只在站点列表能换**：换了整个界面重建。登录以后要换得先退出来。
- **iOS、鸿蒙**：没有工程。相机插件支持 iOS，不支持鸿蒙（鸿蒙样品用粘贴）。
- **macOS 桌面版**没给相机权限，所以不显示扫码按钮。
- **建图页的遥控**不锁横屏（它没有摇杆，只有预览）。
- **A 阶段留下的**：手机上的体检页、导出诊断包、App 版本号上报，这一单没做。
- **触发瞬间的截图**（规范 2.5 里画面左下角的小图）：站点的告警里没有这张图。

## 升级注意

- 站点和 App 没有先后顺序要求：新 App 连老站点只是拿不到二维码（手填照旧）；老 App 连新站点不受影响。
- 库结构没变（53）。
- App 升级后第一次打开是英文；原来存的站点列表还在。
