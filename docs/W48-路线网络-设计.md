# W48 路线网络（路网）设计

> 用户 2026-10-29：「先做人员检测跨板桥接，然后把路线网络……都做了」（之前解释过：在地图上画好可以走的路，机器人沿着走）。怎么做由我定，下面的取舍都是我的判断，标「我定的」。

## 一、要什么

- **安全**：机器人只走人确认过的路（车道、石板路、草坪上某一条），不抄近道到泳池边、花坛、台阶旁。
- **可预期**：出警、巡逻、回待命点每次都走差不多的路，保安、业主看得懂它要往哪走。
- **快**：画好的路上看得清、障碍少，「看得清就快」（决策 76）自然跑得快，对 90 秒到位有帮助。

不做的（第一版）：

- 不按路分档限速（限速区照旧管）。
- 不做单行道、不做路的宽度（路两边能不能走由地图、禁行区、避障管）。
- 不做多楼层。
- 不自动生成路网：装机时工程师或业主在网页地图上画。

## 二、是什么（我定的）

- 一张图（地图号 + 版本）一份路网：**点**（`id, x, y`）和**连线**（两个点，双向）。
- 修订号跟区域一样，站点每改一次加一。
- 站点存、站点发；机器人落盘（断网重启照样按路网走），能力里报收到的修订号，站点按它补发（跟禁行区同一套）。
- 没画路网的图：行为完全不变。

## 三、怎么走（我定的）

去一个点（巡逻点、出警、回待命点、回充电桩）时：

1. 在路网上找路：
   - 从起点「走下路网」到某个点、沿连线走、从某个点「走下路网」到终点。
   - 离开路网的那两小段按**直线距离 × 3** 算代价（宁可多沿路走，不愿意离开路网）；
   - 只考虑离起点、终点 **15 m** 以内的点上下路网。
   - 直接走（不上路网）的代价也按直线 × 3 算，比沿路网更便宜就不上路网（比如两个点就在旁边）。
2. 得出一串途经点：入口点 → … → 出口点。离起点、终点不到 0.5 m 的途经点去掉。
3. **planned 后端**：每一段（起点 → 第一个途经点 → … → 终点）各自用 A* 规划，再拼成一条路径照常跟着走。
   - 途经点只是路过：不停、不对朝向。
   - 重规划（偏离、绕障、提前绕）都从当前位置重新在路网上找路，再拼。
4. **Nav2 后端**：把途经点和终点一起交给 Nav2 的 `NavigateThroughPoses`（行为树跟 to-pose 那份一样，没有原地转，`RemovePassedGoals` 去掉已经路过的点）。
5. 避障、禁行区、守卫、「看得清就快」都照旧：路网只决定往哪走，不放宽任何保护。

某一段 A* 规划不出来（路网上那段被挡死、画到禁行区里了）：这一次不用路网，直接规划到终点，并发一条 `route_net_bypassed` 事件，站点记下原因。

## 四、站点和网页

- 库表 `route_nets(map_id, map_version, body, revision, updated_ms, updated_by)`；历史版本跟布置页的其它几样一样进 `layout_history`。
- 接口：
  - `GET /api/maps/<地图号>/<版本>/route_net`
  - `PUT /api/maps/<地图号>/<版本>/route_net`（业主、管理员）：整份换。
  - 保存时校验：点在地图范围里、不在禁行区里，连线不穿过禁行区；不合格回 400 说清是哪个点、哪条线。
- 下发：保存后发给加载着这一版的在线机器人（`route_net_set`）；机器人报的修订号旧了，站点每拍补发（同一版 30 s 内不重发）。
- 网页：布置页多一个「路网」标签。
  - 地图上点一下放点；先后点两个点连线；点住拖动；选中按删除。
  - 底下列出点数、连线数，以及哪些点没连上任何线。
  - 存的时候带上「是哪张图哪一版」，换了图不许存到别的图上（跟 W44 外审 R5 同一个规矩）。

## 五、机器人这头

- 契约 `d1max_contract/routenet.py`：`RouteNet` 的格式、校验、找路（`route()`），站点、机器人、仿真共用。
- `route_net_set` 命令：
  - 跟 `zones_set` 一样不判过期、修订号挡住旧的；
  - 地图版本不是正在用的拒（`map_mismatch`）；
  - 先落盘（`routenets.json`）再换上。
- 能力里报 `route_net_set: {rev, nodes}`。
- planned 后端 `set_route_net()`；Nav2 后端走 `via`（转接协议加一个可选字段，协议号加一）。

## 六、真机项

- 3al.1：在展厅画一条 L 形路网，派到路网那头的一个点：走的是路网，不抄近道。
- 3al.2：路网中段放纸箱：照常绕过去（或按避障规矩停、报被挡），不乱跑。
- 3al.3：Nav2 后端同样跑一遍：沿途不在节点上停。
