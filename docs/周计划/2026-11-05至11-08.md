## 三、POC 用的界面和遥控（11-06 → 11-07）

对应总表 1–5、7、8、9。都在改名后的新代码上做。

- [ ] **站立、趴下、蹲下**（网页 + 手机）：站点 → 代理 → 旁路下命令（蹲下 = SDK 的 Crawl）；要过运动许可和急停检查，有任务在跑时不让按，按下去要二次确认；结果、失败原因回显。

- [ ] **手机换图进度**：已下载多少 MB、还要多久、校验、切换、定位加载，失败时说原因。
- [ ] **开通码二维码**列出站点真实的局域网地址，不是 127.0.0.1。
- [ ] **告警测试模式**：测试期间产生的告警打上标记，测完一键清掉。

**完成标准**：每一项都有测试（Python 加网页 vitest 加 Flutter），演示站点上用网页和手机都能点通；外审一轮、合并。
