# 事件源接入（摄像头、NVR、门禁转发器把入侵事件报给站点）

> 给接入方看的。站点这一头的设计见 `docs/W00c2c-完工报告.md`（W00c2c）、`docs/W16-完工报告.md`（W16）。

## 登记

在站点机器上：`d1max-site source-add <名字>`。打印一个**共享密钥**，只显示这一次；丢了用 `source-rotate` 换一个，旧的当场作废。

**密钥是 64 位十六进制字符串。算签名前要先解码成 32 字节**，再当 HMAC 的密钥。照字面拿这 64 个字符去算，签名永远对不上，站点回 401。2026-10-08 C40221 现场就踩过一次。

## 请求

`POST https://<站点>:8443/api/incidents`，不用登录。三个请求头：

| 头 | 值 |
|---|---|
| `X-D1MAX-Source` | 登记时的名字 |
| `X-D1MAX-Timestamp` | 现在的时间，**十进制毫秒**（Unix 纪元起），跟站点的钟差不能超过 5 分钟 |
| `X-D1MAX-Signature` | `hex( HMAC-SHA256( 解码后的密钥, 时间戳头的原样字符串 + "." + 原始请求体 ) )`，64 位小写十六进制 |

请求体是 JSON，最少要有：

```json
{"event_id": "nvr-1-20261008-0001", "type": "intrusion", "zone": "front-yard"}
```

- `event_id`：这个源自己的事件号。**同一个源同一个号只处理一次**，重发没事。
- `type`：只认 `intrusion`。别的类型站点只记账、不派狗。
- `zone`：防区名，要先在站点上绑过拦截点：`d1max-site zone <防区> <拦截点>`。

## 例子（Python）

```python
import hashlib, hmac, json, time, urllib.request

SECRET_HEX = "…source-add 打印的 64 位十六进制…"
key = bytes.fromhex(SECRET_HEX)                    # ← 先解码成 32 字节
body = json.dumps({"event_id": "e-1", "type": "intrusion", "zone": "front-yard"}).encode()
stamp = str(int(time.time() * 1000))
sig = hmac.new(key, stamp.encode() + b"." + body, hashlib.sha256).hexdigest()
req = urllib.request.Request("https://site.local:8443/api/incidents", data=body, method="POST",
                             headers={"Content-Type": "application/json",
                                      "X-D1MAX-Source": "nvr-1", "X-D1MAX-Timestamp": stamp,
                                      "X-D1MAX-Signature": sig})
```

站点证书是自签的：接入方要信站点的 CA（`<站点目录>/ca/ca.crt`），或者核对指纹（`d1max-site fingerprint`）。

## 回什么

- **200**：带这条事件的去向。
  - `dispatched`：派了狗；
  - `merged`：同一防区 60 秒内的，并进了已出动的那条；
  - `duplicate`：重发的；
  - `unmapped`：防区没绑拦截点；
  - `ignored_type`：不是入侵；
  - `no_robot`：没有能派的狗；
  - 撤防、访客模式下的防区：只记账，不派狗。
- **401 验签没过**：对外不说具体原因，原因只进站点日志。常见的有：
  - 没把密钥先解码成字节；
  - 时间戳不是毫秒，或者跟站点的钟差了 5 分钟以上；
  - 签的不是时间戳头的原样字符串；
  - 签的不是原始请求体（比如先解析 JSON、再序列化了一遍）。
- **429**：这个源发得太快，被限流了。
