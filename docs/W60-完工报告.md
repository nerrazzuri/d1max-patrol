# W60 网页改版与手机视觉改版 · 完工报告（2026-11-01）

依据：样板画布（网页 4 屏、手机 3 屏）和外审意见，用户 2026-10-31 批准「方向批准，可以进入实现」「就这么定了」。
三条约束：正常状态要安静；保安界面只管值班、不放管理功能；品牌蓝只表示品牌和选中，红黄绿只表示状态。
标志由外部设计方做，不在这一单；代码里标志是一个组件（`shell.tsx` 的 `BrandMark`），到了只换这一处。

## 网页

| 项 | 改了什么 |
|---|---|
| 左侧导航 | 横向页签换成左侧导航，按角色分组：值班（总览、实况、地图、报警记录、录像）、管理（机器人、布置、布防时间、授权和临时撤防、用户）、系统（报表、系统状态），高级（地图管理、定位、诊断、软件升级、系统）收起。保安只有值班一组；经理多机器人（只看）、布防时间、报表；工程师没有用户。站点名、品牌挪到导航顶上 |
| 顶栏 | 只留页面名、布防状态、报警数（点了去报警记录）、时钟、帮助、用户菜单、全部急停 |
| 主题 | 全站默认深色（原来管理页自动换浅色）；「外观」里「默认（深色）/ 跟随系统 / 深色 / 浅色」 |
| 品牌色、字体 | 品牌蓝 = 设计系统的 tertiary（深色 `#4EA8F0`，网页手机同一个值），只给导航选中、焦点、主按钮、选中的机器人；按钮、页签、表头、图例不再用等宽字，等宽只给编号、时间、数字 |
| 总览（原值班页） | 有报警：横幅（P1 红、P2 琥珀）；没报警：一行「一切正常 · 布防状态 · N/M 台机器人在线」。下面四块：地图、待处理报警（列表，点了在地图上选中）、现场画面（两个位）、机器人（每台一条 + 今日巡逻） |
| 机器人卡片 | 第一层名字、状态（在线 / 离线 / 需要关注）、在做什么、电量（大数字 + 条）；第二层定位、网络、今天几趟；有毛病才多一条琥珀色提示，正常不写「正常」 |
| 实况画面 | 顶上名字和状态；底下一条最多三项（在做什么、电量、定位）；报警时换成的固定摄像头现场写「固定摄像头 · 哪里」，跟机器人画面分开 |
| 报表 | 关键指标两组：安防运营（巡逻完成率、平均响应时间、报警确认率）、系统可靠性（机器人可用率、摄像头可用率、人工干预率），每个带「比上一段」（好绿、差琥珀、持平灰）；没有可算的写「—」不写 0。站点 `reports.kpis`（可用率按掉线告警时长扣、同一台重叠的合并；干预 = 那一趟中途出过「要人帮忙」告警） |
| 地图图层 | 基本图层默认开（区域、摄像头、巡逻路线、事件、禁行区），待命点默认关；工程图层（未巡逻时长、定位历史）只给工程师、默认收起 |
| 经理 | 机器人页只看（没有添加、批准、改名、解绑）；站点机器人概况对有排日程权限的开放（改动接口照旧要管理权限）；原来经理进「布防时间」是空白页，修了 |

## 手机（只改视觉和层级，交互不变）

| 项 | 改了什么 |
|---|---|
| 值守页 | 布防 + 天气一行字（不是卡片）；「名字 ▾」点开底部列表选机器人（要关注的在前），在画面上左右滑照旧能切；P1 写什么事、在哪、哪台、多久；状态、最近事件、其余报警不套卡片，用分隔线 |
