## 2. 行为上的变化（升级要注意）

- **站点库结构 55**：`push_devices.provider`（默认 `jpush`）、`push_outbox.done`。自动补列；老的推送号算极光。升了回不去（照旧）。
- **推送登记接口** `POST /api/push/devices`：请求多一个可选的 `provider`（不给算 `jpush`），回执多一个 `providers`。老手机、老站点互相兼容。
- **推送的 `extras`** 多了 `tier`（第几档）。
- **站点配置** `push`：新写法 `{"jpush": {...}, "fcm": {...}}`；老的平铺写法照认。
- **安卓包名**从 `com.d1max.d1max_patrol` 改成 `com.nexusdynamic.warden`：装过旧包的手机会并存两个 App。
- **安卓包多带** `firebase-messaging` 24.1.0、`file_picker`、`share_plus`。
- **手机「保存诊断包」**不再存到 App 自己的目录，改成弹系统保存框。
- **CI**：macOS 桌面版不在主 CI 里了（单独的工作流，只手动触发）；`ci.yml` 的并发组从 `ci-<ref>` 变成 `<工作流名>-<ref>`。
- **`tools/make_release.py`** 必须给 `--gate`（或明说 `--no-gate`）。
