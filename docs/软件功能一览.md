# Nexus Warden 软件功能一览

> 2026-11-01，版本 1.0.0-rc.1。只列代码里已经有的功能，不区分测没测过。更细的技术说明见 `docs/产品能力清单.md`。

## 一、系统组成

- **四足机器人 + 上装**：机器人本体负责走路；上装是我们的硬件包（RK3588 主控、前后激光雷达、前后摄像头、热像仪、聚光灯、警灯、警笛、喇叭、UM982 RTK、4G/WiFi 路由器、SSD）。
- **站点主机**：放在客户现场的一台电脑，管账号、地图、巡逻、告警、录像、推送、远程访问。全部数据留在现场，不经公司服务器。
- **客户端**：网页值班台、安卓 App、Windows / Linux 桌面版。
- **断网照常值守**：局域网内完整工作；外网只用于推送、天气、远程访问和 RTK 改正数据。

## 二、建图与地图

- 建图向导（手机全屏七步）：准备 → 选开法（遥控器 / 手机）→ 走一圈 → 建图 → 禁行区 → 设位置、标原点 → 完成；换手机、关 App 都能接着做。
- 边走边建，手机上实时看图长出来；停下约 80 秒出图，并给出结论：能用 / 有问题 / 说不清。
- 双雷达 + IMU 建图；墙画薄、玻璃后面「看到没走过」的地方不让走；可选回环修正。
- 地图多版本：下发给一台或多台机器人、退回上一版、删旧版、两版叠起来对比；机器人确认收到才算换好。
- 地图编辑：清噪点、橡皮擦、画障碍（玻璃墙、矮台阶）、画笔（首尾接上自动填满）、撤销重做；底图对齐、摆正显示；区域命名；标楼梯、斜坡等特殊地面；另存新版再发布。
- 区域跟着版本走：新版本把旧版的防区、禁行区、待命点作为「待核对」带过来，不悄悄套用。

## 三、定位

- 激光定位，按质量分「可信 / 不太确定 / 迷路了」；不确定时限速，迷路时停车。
- 一致性核对（跟里程、上一个可信位置对），防止锁错位置还报很准。
- 全局重定位：迷路了自己在全图里找回位置。
- 人帮它找位置：保安在地图上把机器人拖到实际位置、指朝向。
- 定位历史和「出过问题的地方」热图。
- 玻璃环境防「假转圈」（雷达 + IMU 先验）。
- RTK：上装 UM982，经商业 CORS 账号（NTRIP）拿改正数据，站点转发给机器人；也支持自建基站。
- 对时：站点当时间源；钟差太大不派命令。

## 四、导航与避障

- 两套导航可切换：自研规划导航；Nav2（Smac + MPPI，按矩形机身算）。Nav2 不在时自动退回自研导航。
- 禁行区、虚拟墙、限速区、临时禁行区（到期自动删）。
- 硬禁区（泳池、落差边）：人遥控也进不去。
- 改区域规矩：收紧立即生效；放宽要确认，机器人确认收到前照旧绕开。
- 只去地图里走过、扫过的地方。
- 激光实时避障；两侧盲区不当空地，转身前先看清；被挡先等、再绕、绕不过体面放弃并说明原因。
- 看得清就快：按前方空多远自动定速度（0.3–1.0 m/s）。
- 第二道速度许可（安全兜底）：快速前进必须有感知给的许可，过期即停。
- 安全掉头、头尾都能当头走、雨天滤点。
- 路网：画好可以走的路，机器人沿路走，不抄近道穿草地、花坛。
- 遥控：手机、网页、桌面版都能；要先拿控制权、没画面不许动、断线即停；桌面版键盘遥控。

## 五、巡逻与任务

- 巡逻路线：图上点巡检点，设停留时间、拍照、热像、测温、朝向；存之前检查走不走得通、进没进禁行区。
- 路线绑地图版本；路线、禁行区、待命点、摄像头每次保存留历史版本，一键退回。
- 排程：几点出发、多久一趟、派哪台；夜间加密、随机顺序；到点没派出去会报警。
- 临时巡逻：派之前估时、提示会不会撞上排程；被拒时说原因，并给「去处理」按钮。
- 「今天的巡逻」：每一轮完成、没完成、在跑、下一次一目了然。
- 待命点（多个）、原点；入侵出警打断巡逻。
- 自动回充：低电量去充电桩，充好出桩。
- 多台机器人：按电量、定位质量挑一台；错开充电。
- 新加入的机器人默认只接手动派的任务，确认没问题再放开。

## 六、安防

- **入侵来源**：固定摄像头（ONVIF 人形 / 区域检测）、外部系统签名回调（周界、门禁等）、机器人自己看到人。
- **布防**：模式有布防、留守、临时撤防；每周布防时间表（按防区，节假日例外）；授权（比如工人某时段在某区域，看到人不报警）。
- **派遣**：每个防区设拦截点（设置时就检查到不到得了）；挑最合适的机器人去，到了自动抓拍。
- **告警**：
  - P1 / P2 / P3 三级，颜色、形状、文字三重区分；
  - 保安只看四类事：有人闯入、起火或过热、机器人需要帮忙、机器人掉线；技术类提醒发给管理员，写成人话；
  - 入侵类手机一直响，直到有人确认；
  - 推送：极光（含各大厂商通道）+ FCM，只推 P1 标题；
  - 告警带现场照片、位置、录像；处理三按钮：「我来处理」「确认有人」「误报，关掉」；P2 可以搁置。
- **分级驱离 L0–L4**：观察 → 灯光 → 语音警告 → 警笛 → 人工接手；每 30 秒自动升一级（人动过就不再自动升）；话术中、英、马来文轮放；声光每次最长 45 秒，靠站点续，断网自动关；人走了自动收场。
- **人员检测**：前摄像头 + 雷达测距，判断有人、靠近、走了。
- **保持距离**：驱离时人靠近 3 m 机器人后退到 4 m，只退不进；无路可退原地站定报警。
- **热成像**：第三路画面、夜里找人、起火和过热告警、巡检点测温、镜头被挡检测。

## 七、视频、录像与证据

- 实时视频：前后摄像头和热像推到站点再分发；有人看才拉流。
- 值班页两个画面位，按紧急程度自动挑机器人；断线停在最后一帧并写明断了多久。
- 实况页：所有机器人一起看。
- 连续录像：一分钟一段上传站点，断网先存在机器人上、回来补传；站点留 30 天。
- 回放：24 小时时间轴标出告警，跳转、连续播、倍速、前后摄像头切换。
- 证据加密：机器人上的照片、录像用站点公钥加密，机器人自己解不开。
- 隐私：证据留 90 天、可标「留着」、可按时间段删；谁看过、导出过都记审计。

## 八、上装外设与设备健康

- 左右聚光灯、警灯、警笛、喇叭（录音话术 / TTS，有优先级；功放不用时系统静音）。
- 继电器板：每秒通信一次，断开 5 秒板子自动全关；每次开都带最长时间。
- 设备健康：每路设备报「正常 / 告警 / 故障 / 没装」，手机和网页都能看。
- 温度与风扇：SoC、硬盘温度、3 只风扇停转报警；过热分三级：报警 → 降负载 → 结束巡逻回充。

## 九、运动安全与自我保护

- 全部急停（网页、App 顶栏常在）；急停后旧目标不会复活。
- 运动旁路只收认证过的命令；速度命令带有效期，过期自停。
- 翻倒、被抱起、被撞检测：停车、报警、解锁前要补完安全动作。
- 天气：查天气或手动切；雷暴停巡逻，雨天限速，打滑报警。

## 十、站点：身份、账号与安全

- 自建证书体系：机器人一台一张证书，双向认证；可吊销；证书剩 45 天自动续签（新私钥不出机器人）。
- **机器人添加**：手机扫机器人贴纸 → 选 WiFi → 连机器人热点 → 发给机器人 → 站点上管理员核对后批准；工程师也可以用一次性开通码。
- **解绑**：站点上解绑，机器人自动清机；不在线时用公司解绑令。
- **设备身份**：只有原厂上装（带出厂证书、现场答得上题）才能加入站点；仿冒的只看到「此设备无法加入站点，请联系供应商」，尝试记录给公司。
- 手机扫站点二维码添加站点（钉住站点证书指纹）。
- 角色：保安、经理、管理员、工程师（临时账号，限时）、只看；不用登录也能申请账号，管理员批准时选权限。
- 审计：谁撤的防、谁关的报警、谁看过证据。重要操作再输一次密码。
- 口令、备份加密存储。
- 站点 VPN（WireGuard）：只开一个 UDP 端口；WiFi / 4G 切换不断；机器人、手机各有固定隧道地址；工程师临时 VPN 跟账号一起到期。

## 十一、运维与升级

- 每小时加密备份，每周自动抽查；一条命令恢复、演练。
- 健康检查、30 天运行指标、问题用人话提醒。
- 远程运维：
  - 机器人：看诊断快照和服务日志、开详细日志、重启服务或整机、对时、清理空间、立即续签证书；
  - 站点：重启服务、恢复备份、发送测试推送；
  - 要 root 的动作只由白名单「特权执行器」做。
- 诊断包：可选时间段，自动打码，网页和手机都能下载。
- 升级：
  - 站点：网页上传公司签名的包，先备份再升，失败自动回退；
  - 机器人：签名包验过才装，所有服务重启，旁路程序在机器人上编译，编不过不切换；
  - App：站点分发新版，App 提示更新、直接安装；
  - 站点、机器人、App 版本兼容自动核对。
- 报表：值班日报、月报（巡逻趟数、事件、误报率），导出 PDF。
- 开站清单（九项）、按角色的上手导览、常见问题。

## 十二、客户端

- **网页值班台**：深色；左侧导航分「值班 / 管理 / 系统」三组（地图管理、定位、诊断、升级收在「高级」）；按角色只显示该看的（保安只有值班一组）；总览页有报警时显示横幅、平时一行「一切正常」；中英文。
- **安卓 App**：值守首页（布防状态、天气、P1 红条、机器人切换、画面）、告警处理（先看现场照片）、遥控（横屏）、地图、派巡逻、建图向导、添加机器人、管理 / 日程 / 我的（按角色）、设置页（语言、外观、后台值守、推送状态、检查更新）；深浅色、竖横屏。
- **桌面版**：Windows、Linux，带键盘遥控。

## 十三、交付与出厂

- 站点、机器人装机脚本（可离线装）+ 装完自检；装机清单、使用手册、验收报告模板、软硬件版本对照表、隐私说明。
- 正式发行：离线签名、发行闸核对、发行记录；安卓正式签名；出厂工作站一条命令烧一台上装（设备钥匙、出厂证书、贴纸文件）。
- 公司钥匙四把（发行、解绑令、出厂、安卓）可轮换、可作废。
