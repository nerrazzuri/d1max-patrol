# 远程运维手册（W55）

给公司工程师用：不到现场，怎么连上、看问题、处理、升级。设计见 `docs/W55-远程运维-设计.md`。

## 一、连上站点

工程师只经**站点 VPN** 连入（决策 71），不开公网端口。

1. 站点管理员在网页「账号」点「给工程师开临时账号」：填名字、选 4 / 24 小时，勾选「同时发放 VPN 配置」（默认勾选），再输一次自己的密码。
2. 页面显示一次账号、密码和 VPN 配置文件（`d1max-eng-….conf`），管理员把三样发给工程师。关闭后无法再查看。
3. 工程师把配置导入 WireGuard，连上后：
   - 浏览器打开 `https://172.29.70.1:<站点端口>`（站点在 VPN 里的地址），用临时账号登录；
   - `ssh` 到站点主机 `172.29.70.1`；接入了 VPN 的机器人（4G 的）在 `172.29.70.10` 起，直接 `ssh`（转发只放行 22 端口）；
     在现场局域网里的机器人，先 `ssh` 到站点主机再跳过去。SSH 账号、密码见现场记录。
4. 到期后账号停用、VPN 地址收回（站点定时检查），不需要手动收回。

站点没装 VPN 时（「系统」页写「未安装」），先在站点主机上 `d1max-site --home <站点目录> vpn init --endpoint <域名或公网IP>`（现场路由器把 UDP 51820 转发到站点主机），或者只能在现场局域网里连。

## 二、看问题

| 想看什么 | 在哪 |
|---|---|
| 站点各项是否正常、每台机器人设备健康 | 网页「高级 → 诊断」 |
| 某台机器人的诊断快照：各服务状态与重启次数、版本、内存、磁盘、温度、网络、时间同步、证书到期、现场配置（密码类已打码） | 「诊断」页该机器人下「远程运维 → 诊断快照」；手机：机器人页「管理 → 远程运维」 |
| 某个服务的日志（最近 1 小时到 7 天） | 同上，选服务和时间段「查看日志」，可下载 |
| 打开详细日志（排查时用，1 小时后自动恢复） | 同上「详细日志 1 小时」 |
| 站点运行指标（磁盘、在线机器人、待上传证据、响应延迟、P1 告警），最近 30 天 | 「高级 → 系统」 |
| App、网页报上来的错误 | 诊断包里的 `client_errors.json`（站点留 14 天） |
| 全部打包带走 | 「诊断」页选时间段「打包日志」：站点日志、事件、命令、审计、每台在线机器人的诊断快照与主要服务日志、App 与网页错误。不含密钥、令牌、数据库 |

## 三、处理

| 操作 | 在哪 | 限制 |
|---|---|---|
| 重启某个服务 | 机器人「远程运维」选服务「重启服务」 | 只能是我们自己的服务（`d1max-*`）；只在空闲时 |
| 重启机器人 | 「重启机器人」 | 再输一次密码；只在空闲时（不在巡逻、建图、遥控）；接下以后到重启前不接新任务 |
| 立即对时 | 「立即对时」 | |
| 清理空间（旧软件版本、系统日志） | 「清理空间」先看能清多少，再点「清理」 | 正在用的和上一版不删 |
| 立即续签证书 | 「立即续签证书」 | 平时自动续，见第五节 |
| 重启站点服务 | 「高级 → 系统 → 重启站点服务」 | 再输一次密码；值班台中断约一分钟 |
| 恢复最近一次备份 | 「系统 → 恢复最近一次备份」 | 再输一次密码；备份之后的改动丢失 |
| 测试推送 | 「系统 → 发送测试推送」 | 给自己账号登记的手机发一条 |

以上都记在审计里（谁、什么时候、对哪台）。

更深的问题经 VPN `ssh` 上去处理。机器人上的服务由 systemd 管，日志用 `journalctl -u d1max-agent` 等（系统日志在机器人上保留 14 天、最多 500 MB）。

## 四、升级

升级顺序照 `docs/版本兼容与升级顺序.md`：先站点、后机器人、最后手机。

1. **站点**：「高级 → 软件升级 → 升级站点」，选公司发的升级包（发行包目录打成的 `.tar.gz`），再输一次密码。站点先备份、验签，升级中会重启；新版本起不来自动回退到原来的版本。页面每 10 秒刷新结果。
2. **机器人**：同一页上传同一个包，下载到机器人、选「现在」或「充电且空闲时」切换。切换后机器人上我们所有服务都重启（不只代理），包里的服务配置有变化的一并更新；包里带运动控制旁路程序的源码，机器人上配了厂商 SDK（`D1MAX_ROBOT_SDK`）就当场编译，编不过不切换。
3. **手机 App**：同一页「App 安装包」，选平台，上传安装包和它的签名清单（发行时一起出，见 `docs/正式发行手册.md`）。手机登录后底部提示新版本；也可以在 App「设置 → 检查更新」。安卓手机第一次要允许本应用「安装未知应用」。

## 五、证书

机器人证书到期前 45 天站点自动续签（新私钥在机器人上生成，不出机器人），一年一签；新证书先挂着、旧证书照常可用，机器人确认换上（或拿新证书连上来）才生效；机器人正忙就等一小时再试（换证书要重启代理，只在空闲时换）。续签失败报 P2「证书自动续签失败」，第二天自动重试，也可以手动「立即续签证书」。手动续签的老办法见 `docs/证书续签.md`。

## 六、权限

远程运维只给**管理员**和**工程师**。保安、经理、只看账号看不到这些入口，站点也拒绝。
