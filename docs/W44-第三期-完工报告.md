## 这一期做了什么

「管理 → 布置」一页：一张大地图，上面五个标签 —— **防区、禁行区、巡逻路线、待命点、摄像头**。选哪个只能改那一样，别的四样淡着画；
右上角「保存」（这个标签有没存的改动才亮）和「历史版本」。旧的「地图与防区」「巡检路线」两页的地址跳到这里。

**站点后端**

| 新东西 | 做什么 |
|---|---|
| 历史版本 `layout_history.py`（库结构 63） | 防区、禁行区、路线、待命点、摄像头每次保存成功留一份快照（谁、几点；每样留 50 份）。`GET /api/layout/history`、`POST …/{id}/restore` 一键退回 —— 走原来的保存路径：禁行区放宽照样要确认、机器人照旧守旧的；路线照样带修订号；摄像头快照不带口令，退回一台已删的提醒重填口令 |
| 摄像头在图上的位置 | 摄像头多 `map_id`、`map_version`、`x`、`y`、`yaw`、`fov_deg`；`/api/admin/cameras` 收 `placement`（不带就不动），`/api/cameras` 带回给保安地图页 |
| 路线逐段查 | 存路线之前，相邻两点用跟机器人同一份规划（带禁行区）查走不走得通，走不通的那一段回 `segment: [i, i+1]` |
| 网页放宽禁行区要密码 | 网页（cookie 会话）确认一份比在生效的松的禁行区，要 `confirm_password`；收紧、手机照旧 |

**网页**

- 外框 `layoutpage.tsx`：选图、五个标签（地址 `#/admin/layout?tab=…`）、淡层、保存、历史抽屉（退回前确认，禁行区、路线写清楚退回也要走确认）、
  保存回 409 写「刚才有人改过，先看一下」+「看最新的」、切标签 / 切图前问没存的。
- **防区**：圈一块、起名、勾哪些摄像头归它管（原本就归它的不能取消，要去别的防区勾）、删要确认、「去设它的布防时间」。
- **禁行区**：禁行区 / 虚拟墙 / 限速区 / 人员忽略区 / 抹掉区；临时的选 1、3、7、30 天；状态说人话（已生效 / 等你确认：删了哪些，确认前机器人照旧绕开 /
  等机器人确认中：哪台还没收到）；确认那一句换成人话、勾上才能确认；放宽的再输一次密码。
- **巡逻路线**：现有路线编辑（外审过的点运算、拖点、转朝向、晚到回包、排程）嵌进来，图和保存按钮用外框的；不显示坐标数字；
  走不通的那一段画红色虚线；「拍热像」「量温度」灰着写「热像到货后开放」。
- **待命点**：每台机器人的待命点画成图标（默认的实心）；拖图标、拖箭头、选中后点图挪；加一个（选哪台、起名）；设默认；删；充电桩只画出来看。
- **摄像头**：放到图上、拖箭头调朝向、填张角；旁边实时画面对照；改连接信息（口令不回显、空着不改）；删。「系统」页底下暂挂的摄像头那块拿掉了。
- **保安地图页摄像头图层**（第一期留下的）：扇形 + 名字，点了看实时画面。

## 我替用户定的（Rulings）

1. 路线页不重写，加「嵌进布置页」的模式：原来的晚到回包、409、排程这些外审过的逻辑和 30 多条测试原样留着；单独那种模式现在只有测试在用。
2. 排程里「派哪台机器人」没加：契约的排程条目没有指定机器人的字段，照旧按派遣规矩挑。
3. 路线走不通的那一段不标点（`index` 是空），只画那一段 —— 点本身没错。
4. 旧的「地图与防区」页（`zonesadmin.tsx`）没删：入口已经没了（地址跳布置），它的功能（抹掉区、人员忽略区）第三、四期都搬进了禁行区标签；
   但它的外审测试顺带测着「转过的图上点哪存哪」这类地图组件的算法，删了会丢这些测试。外审时可以一起看要不要挪测试再删。
5. 手机确认放宽禁行区这一期不要密码（手机只改用词）。
6. 摄像头一定归一个防区：在防区标签里，原本就归这个防区的摄像头不能取消勾选，要去别的防区勾它。
