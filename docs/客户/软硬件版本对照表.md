# Nexus Warden 软硬件版本对照表（1.0.0-rc.1）

列出 1.0.0-rc.1 支持的设备和版本，以及每一项的验证程度。**对客户承诺时只承诺「现场已验」的组合**；其他组合需在该现场验收时补验（`docs/客户/现场验收报告模板.md`）。

验证程度：

- **现场已验**：在真机器人、真设备上验过；
- **已开发·待现场**：代码完成并通过测试，未在真设备上验过；
- **待到货**：软件接口已做，硬件未到。

## 一、机器人

| 项目 | 支持的型号 / 版本 | 验证程度 | 备注 |
|---|---|---|---|
| 四足机器人本体 | 厂商 D1 Max | 现场已验（C40221、C40011 两台） | |
| 机器人运动平台软件 | 0.2.4 | 现场已验（C40221） | 平台版本决定 SDK 版本，见下一行 |
| 厂商机器人 SDK | 0.1.1（配平台 0.2.4） | 现场已验 | SDK 与平台版本不对应会连不上；其他平台版本先查厂商对照表 |
| 机器人感知计算机 | NVIDIA Orin，JetPack R36.4.7（Ubuntu 22.04） | 现场已验（C40221） | 目前我们的机器人端服务全部运行在这里 |
| 激光雷达 | 厂商配的前后两台 RS-Airy | 现场已验 | 建图、定位、避障 |
| 机器人摄像头 | 厂商配的前后摄像头（RTSP） | 现场已验 | |

## 二、上装（V2，硬件版本 D）

| 项目 | 型号 | 验证程度 |
|---|---|---|
| 主控算力板 | ROC-RK3588-RT | 待到货（到货后机器人端服务迁到这块板，人员检测仍在 Orin） |
| RTK 定位 | UM982 双天线 | 待到货 |
| 4G + WiFi 路由器 | USR-G806w-G | 待到货 |
| 驱离外设 | 聚光灯、警灯、警笛（4 路 Modbus 继电器），喇叭 + 功放 | 待到货（软件已按硬件说明接好） |
| 热成像相机 | 见 `docs/上装V2-硬件对接说明.md` | 待到货 |

不带上装时：报警、拍照录像、巡逻、避障照常；**没有灯光、警笛驱离和 RTK**。

## 三、站点主机

| 项目 | 要求 | 验证程度 |
|---|---|---|
| 操作系统 | Ubuntu 22.04 LTS（x86_64） | 已开发·待现场（开发机与演示环境验过；干净主机装机待现场） |
| Python | 3.10 及以上（系统自带） | 同上 |
| 硬件 | 4 核、8 GB 内存、512 GB 以上硬盘（录像按路数和保存天数另算） | 建议值 |
| 网络 | 与机器人、摄像头同一局域网；固定 IP | |

## 四、客户端

| 项目 | 要求 | 验证程度 |
|---|---|---|
| 网页值班台 | Chrome（最新两个大版本） | 现场已验（演示站点，真 Chrome） |
| 其他浏览器 | Edge（Chromium 内核）可用；Firefox、Safari 未验 | 未验 |
| 安卓 App | Android 10 及以上（热点配网需要 10 以上；通知权限 13 以上要手动允许） | 已开发·待现场（真手机全流程待验） |
| 推送 | 有谷歌服务的手机：FCM；国内品牌手机：极光推送 | 已开发·待现场 |
| iOS、鸿蒙 | 不支持（后续版本） | — |

## 五、摄像头

| 项目 | 要求 | 验证程度 |
|---|---|---|
| 协议 | ONVIF 或 RTSP（H.264） | 已开发·待现场（演示环境用模拟摄像头验过） |
| 品牌 | 不限品牌，只用标准协议；不用厂家私有接口 | 现场验收时逐台验 |

## 六、版本搭配

站点、机器人、App 用同一个发行版本（1.0.0-rc.1）。升级顺序：先站点，后机器人，最后手机。详见 `docs/版本兼容与升级顺序.md`。
