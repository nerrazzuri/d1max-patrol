# Nexus Warden 使用手册（1.0.0-rc.1）

本手册写给使用系统的客户：管理员、经理、保安。装机、出厂烧写、升级由工程师做，见 `docs/装机清单.md`、`docs/正式发行手册.md`。

## 一、系统组成

| 部分 | 放在哪里 | 做什么 |
|---|---|---|
| 四足机器人 | 现场 | 按路线巡逻；发现人员时报警、拍照录像、就地驱离（灯光、警笛） |
| 站点主机 | 现场机房或弱电间，一台小电脑 | 保存地图、路线、日程、报警、录像；连接摄像头；给网页和手机提供服务 |
| 网页值班台 | 值班室电脑的浏览器（推荐 Chrome） | 保安值班；管理员做设置 |
| 手机 App（安卓） | 管理员、保安的手机 | 收报警推送、处置报警、看实况、遥控机器人、配网 |

全部设备在现场局域网内工作，不经过公司服务器。外网断开时巡逻、报警、录像照常进行；只有手机推送、天气和远程访问（VPN）需要外网。

## 二、账号与权限

| 角色 | 能做什么 |
|---|---|
| 管理员（最高权限） | 全部功能：账号、布防时间、机器人、布置（地图、路线、区域）、软件升级、系统设置 |
| 经理 | 看全部页面，处置报警，派遣巡逻；不能改系统设置 |
| 保安 | 值班页面：看实况、处置报警、派遣巡逻、急停 |
| 只看 | 只看，不能操作 |
| 工程师（临时） | 现场装机、维护用，到期自动失效 |

- 第一次装机时工程师创建管理员账号，交给客户管理员后请**立刻修改密码**（右上角用户菜单 →「修改密码」）。
- 新账号：在「管理 → 用户」添加，或者让对方在手机 App 上申请、管理员批准。
- 人员离职：在「管理 → 用户」删除其账号，并在「管理 → 授权和临时撤防」检查是否还有他的授权。

## 三、网页值班台

登录站点地址（工程师交付时给出，形如 `https://<站点地址>:8443`）。第一次打开浏览器会提示证书不受信任：按交付时给的证书安装说明装一次站点证书，以后不再提示。

**保安页（深色）**

| 页面 | 用途 |
|---|---|
| 值班 | 当前报警、机器人状态、今日巡逻 |
| 实况 | 机器人和摄像头的实时画面 |
| 地图 | 机器人在地图上的位置、路线、区域 |
| 录像 | 按时间、机器人、摄像头查找录像 |
| 报警记录 | 全部报警和处置过程 |

顶栏始终显示：报警数、布防状态、**「全部急停」**（让所有机器人立即停下并保持姿态）。

**管理页（浅色，仅管理员）**

- 常用：现场概况、布防时间、授权和临时撤防、用户、机器人、报表。
- 布置：地图上的路线、禁行区、待命点、拦截点、摄像头位置。
- 高级：地图管理、定位、诊断、软件升级、系统。高级页面一般由工程师操作。

## 四、手机 App

1. 安装工程师交付的安卓安装包。以后站点升级后，App 会提示「有新版本 App」，点「更新」即可。
2. 添加站点：点「添加站点」→「扫码」，扫网页「管理 → 高级 → 系统」里显示的二维码（也可「粘贴配对码」），再输入账号密码。
3. 第一次打开会请求通知权限：**必须允许**，否则收不到报警。
4. 底部栏：值守、机器人、地图、记录、管理（管理员）、日程、我的。
5. 「我的 → 使用教程」有分步引导；「管理 → 待处理」列出需要管理员处理的事项。

## 五、布防与撤防

- 「管理 → 布防时间」设置每周的布防时段。布防中发现人员即报警；撤防（留守）时只记录不报警。
- 临时有人进入（施工、来客），在「管理 → 授权和临时撤防」添加临时授权或临时撤防，到时自动恢复。
- 顶栏和手机都显示当前状态：布防中 / 留守 / 临时撤防（到几点）。

## 六、报警与处置

1. 报警到达：网页值班页弹出，手机推送通知。最高级别的报警会一直响铃，直到有人在 App 里确认（只点开通知不算确认）。
2. 打开报警：看现场照片、现场录像、在图上的位置。
3. 选择处置：
   - **「我来处理」**：确认由你负责，其他人看到「某某已确认」；
   - **「就地驱离」**：机器人开灯光、警笛（按警笛级别）；
   - **「误报」**：标为误报并关闭。
4. 处理完关闭报警。全部过程记在「报警记录」里，「报表」可导出。

## 七、巡逻

- 路线：管理员在「布置」里画路线；新地图上的禁行区要先确认，机器人才会出发。
- 日程：「日程」里设置每天几点走哪条路线、用哪台机器人。
- 临时派遣：值班页或手机「机器人」页选机器人、选路线，派出。
- 巡逻结束机器人回到待命点。空闲时电量低于 30% 会自动去充电桩充电（需要安装充电桩）。

## 八、安全须知

- **急停**：网页顶栏「全部急停」、手机机器人页的「叫停」，或机器人厂商遥控器的急停键。叫停后机器人原地保持姿态。
- 机器人运动时与其保持至少 1 米距离；不要在楼梯、湿滑地面、玻璃幕墙附近安排路线，除非工程师现场验证过。
- 厂商遥控器或厂商 App 接管机器人时，我们的系统会暂停控制，接管结束后自动恢复。
- 驱离用的警笛音量大：靠近机器人检查时先在 App 里停止驱离。

## 九、常见问题

| 现象 | 先做什么 |
|---|---|
| 收不到手机推送 | 手机设置里允许本 App 的通知、关闭省电限制；网页「管理 → 高级 → 诊断」看「手机推送」是否正常 |
| 网页打不开 | 确认电脑与站点主机在同一网络；站点主机是否开机；地址、端口是否正确 |
| 机器人显示「离线」 | 检查机器人电源、WiFi；在「管理 → 机器人」看最后在线时间 |
| 机器人不出发，提示定位不可用 | 让机器人回到待命点附近重新定位；仍不行联系工程师 |
| 报警太多（误报） | 在报警里标「误报」；经常发生的位置请工程师调整区域或灵敏度 |
| 忘记管理员密码 | 联系公司售后（需核实身份），工程师现场重置 |

**售后联系方式**：交付时写在《现场验收报告》首页。
