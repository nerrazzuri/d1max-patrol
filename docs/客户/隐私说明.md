# Nexus Warden 隐私说明（1.0.0-rc.1，草稿）

> 草稿（W58），供客户合同附件和应用商店上架使用。发布前须由公司确认，按客户所在地的法律（如马来西亚 PDPA）审阅。

## 一、数据存在哪里

Nexus Warden 的全部数据存放在**客户现场的站点主机**上，不上传到 Nexus Dynamic 的服务器。公司只有在客户主动导出并交给公司时（例如诊断包），才会接触到这些数据。

## 二、站点上保存什么、保存多久

| 数据 | 内容 | 默认保存 |
|---|---|---|
| 运行记录 | 每趟巡逻的经过、巡检照片、人员截图、报警现场照片 | 90 天 |
| 录像 | 机器人和摄像头的录像 | 30 天 |
| 位置轨迹 | 机器人走过的位置 | 30 天 |
| 报警记录 | 报警内容、谁确认、谁处理、结论 | 不自动删除 |
| 审计记录 | 谁在什么时候看过照片、录像、实时画面，导出过什么，改过什么设置 | 不自动删除 |
| 账号 | 账号名、显示名、角色、密码（只存加密后的摘要） | 删除账号时删除 |
| 手机推送号 | 每部手机的推送号（用于发报警） | 手机退出登录或失效时删除 |
| App 错误记录 | App 出错时的页面、错误信息、App 版本、手机系统类型 | 14 天 |
| 导出包 | 管理员导出的巡逻记录 | 7 天 |

- 标为「留着」的运行记录和录像（作证据用）不按期删除。
- 当事人要求删除时，管理员可按时间段删除运行记录和录像（含备份），操作记入审计。第一版不做人脸识别，无法按人检索。
- 备份文件加密保存，由客户管理员保管密钥。

## 三、会离开现场的数据

| 去向 | 发送什么 | 什么时候 |
|---|---|---|
| 手机推送服务（安卓：Google Firebase 云消息或极光推送；iOS 上线后：Apple 推送服务） | 推送号、站点名、报警类型和标题（例如哪个防区入侵） | 有报警要通知手机时 |
| 天气服务（open-meteo.com） | 站点的大致坐标（保留两位小数，约 1 公里） | 开启天气功能时，定期查询 |
| RTK 改正服务（如使用第三方 NTRIP 服务） | 机器人的大致位置 | 开启 RTK 且使用第三方服务时 |
| 站点 VPN | 加密隧道，不经公司 | 客户开启 VPN 时 |

照片、录像、地图、位置轨迹**不会**发给推送服务或其他第三方。

## 四、手机 App 保存什么

App 在手机上只保存：添加过的站点地址和证书指纹、登录状态、语言设置。照片、录像不在手机上长期保存（客户主动分享、下载的除外）。

App 申请的权限：

| 权限 | 用途 |
|---|---|
| 相机 | 扫站点二维码、扫机器人贴纸 |
| 通知 | 收报警 |
| 网络、更改网络连接 | 连站点；配网时连机器人热点 |
| 安装应用（安卓） | 从站点更新 App |
| 前台服务、保持唤醒、忽略电池优化（安卓） | 后台值守：App 在后台时也能及时收到并响铃报警 |
| 极光推送附带的权限（安卓，使用极光时） | 极光 SDK 自身要求；Nexus Warden 不使用定位、不读取其他应用 |

## 五、摄像头与人员

- 机器人和摄像头会拍到进入监控范围的人。客户应按当地法律在现场设置告示。
- 第一版不做人脸识别，不建立人员档案。
