# POC 界面与遥控 设计（周计划第三节，2026-11-05）

依据 `docs/周计划/2026-11-05至11-08.md` 第三节，共 8 项。全部在改名后的代码上做，分支 `poc-ui-teleop`。
每项都有测试（Python、网页 vitest、Flutter），演示站点上用网页和手机都能点通；最后外审一轮再合并。

## 1. 站立、趴下、蹲下

- **命令**：新增 `posture`，载荷 `{mode: stand|lie|crawl}`。它不是任务，不占任务槽。代理收到后自己检查，过了才执行，跟警示 `deter` 一样：
  1. 有没在结束的任务在跑 → `busy: 正在执行任务 <id>`；
  2. 正在叫停（`halting`）；
  3. 翻倒或被抱起（`force_gate`）；
  4. 在充电桩上（`motion_gate`）；
  5. 急停生效（`estop`）。
- **执行**：检查都过了，调 HAL `set_motion_mode(mode)`。HAL 要等状态帧跟上（最多 10 秒），回执里带上最终姿态。
  - 站点给这条命令的回执超时设为 20 秒，不用默认的 10 秒。
- **旁路（C++）**：新增 `crawl` 命令，执行 `Crawl(3000)`。SDK 0.1.1 的 `sdk_client.hpp` 里有这个接口，跟 lie 一样要求握着控制权。Python 侧新增 `SidecarDeviceBackend.crawl()`；HAL 收到 `crawl` 后等 SDK 进入 `CRAWL` 状态。
  - **旁路要在机器人上重新编译**，第一次上真机要用户在场：排到下周，跟速度档一起。
- **仿真适配器**：同样支持这三种姿态，演示站点能点。
- **能力**：代理报 `tasks.posture = {modes: [...]}`。站点、网页、手机只显示这台机器人报了的那几种。
- **站点**：
  - 接口 `POST /api/robots/<id>/posture {mode}`，权限 `teleop`，跟遥控一样：会让机身动的手动操作。
  - 写审计；拒了回 409，把机器人给的原因原样带上。
- **网页和手机**：机器人详情里加三个按钮，点了先弹二次确认，写明会发生什么。之后显示结果或失败原因；有任务在跑时按钮置灰，旁边写原因。

## 2. 遥控速度档（用户 11-05 改版：按速度分，自动换 SDK 档位）

用户定的：手机不分「慢 / 中 / 快」，按速度分 **0.3 / 0.6 / 1.0 / 1.3 / 1.6 / 2.0 m/s**，目前最高到 SDK 中速档；只在遥控时用，遥控结束、断线、急停、叫停后回低速档。自动巡逻、回原点一律低速档。

SDK 0.2.0 `SetSpeed` 文档：低速档比例 1.0 = 1.0 m/s（横移 0.5、转向 1.5 rad/s）；中速档 2.0 m/s，前进超过 1.0 m/s 时横移为 0、转向比例 1.0 = 1.0 rad/s；高速档 3.0 m/s（这次不用）。

- **站点**：安全设置 `teleop_speeds` 是一张速度表（1–8 个，严格升序，每个 0 < v ≤ 2.0），默认上面 6 个；管理员在网页「系统」里改（`GET/POST /api/teleop-speeds {speeds}`）。租约带 `max_vx_mps` = 表里最快的。手机在 `granted` 里拿到这台能用的那几档：不超过这次前进上限的（差 0.05 以内也算，低速档实测 0.98 也给 1.0 档）；都比上限慢得多（老机器人只有一半）就把上限补上。前进上限 = min(表里最快, 机身；能换中速档按 `max_vx_teleop`)；转向、横移按低速档同比例，不跟着中速档变快。
- **手机**：一个速度一个按钮，默认 0.6；摇杆满推 = 选的速度，转向、横移按「选的速度 ÷ 1.0」缩放（1.0 起就满）；每帧带 `vmax`（选的速度）。选了超过 1.0 的显示「超过 1.0 m/s 用中速档：不能横移、转向变慢；换档要先松开摇杆」。上次选的速度记在本机。
- **代理**：前进按 `vmax` 夹。`vmax` 超过 1.0（且 HAL 报 `max_vx_teleop`、租约带了 `max_vx_mps`）要中速档，否则低速档。**换档只在摇杆回中时做**：推着杆换了档位，丢帧 `gear_wait`、停下等松杆；档位报上来之前丢 `gear_switching`、不下速度。中速档每秒续一次；遥控结束先停车再要回低速档。中速档前进超过 1.0 时横移给 0。全机器人限速、硬禁区守卫照旧在后面算。
- **HAL**：能力报 `max_vx_teleop`（中速档前进最快；旁路不让换是 0）；`set_teleop_gear(level)`、`teleop_gear()`。中速档换算用 `--mps-per-unit-mid`（缺省 = `--mps-per-unit` × 2，真机测过再填），前进超过 1.0 时转向按 1.0 rad/s 换、不横移。
- **旁路（协议 12，要在机器人上重编）**：`{"cmd":"gear","level":1|2}`（要认证、插队），`level` 不超过新参数 `--teleop-max-gear`（缺省 1 = 不让换）。临时档 3 s 没续（`gear` 或 `vel`）、急停、丢控制权、发它的连接断了都回 `--speed-level`；换档那一下作废速度目标和净空许可（许可的比例按旧档换的）；档位报上来之前安全门不放行。净空许可的 m/s 换比例跟着当前要的档走。hello 带 `teleop_max_gear`。
- **兼容**：老旁路（≤ 11）或 `--teleop-max-gear 1` → 手机只显示到 1.0 的档；老代理不认 `vmax`，按租约 `max_vx_mps` 夹；老站点不给速度表 → 手机不显示档位，照旧按站点限速。
- **已知限制**：开了净空许可门（`--require-clearance`）时，前进比例超过 0.5 要感知节点的许可；感知节点按刹车距离给的 `vmax` 目前最多 1.0 m/s，真机上中速档要放开感知那头的上限才会超过 1.0（下周真机一起定）。

## 3. 遥控指令被丢的原因

- **原因码**：代理的帧闸原来记 `epoch / seq / late`，新增两条：
  - `no_video`：画面断了，不执行；
  - `video_recovered`：画面断过又恢复以后，要先收到一帧摇杆回中的，才接着执行。画面回来时操作员手可能还推着杆，免得机器人突然冲出去。
- **回传**：每次续租的回执带上 `drops`（各原因的累计数）和最近一条原因、时刻。站点原样转给手机（跟硬禁区提示走同一条路）。
- **手机提示**：
  - `late` →「指令被判迟到：钟差或网络」
  - `video_recovered` →「画面刚恢复，请先松开摇杆」
  - `no_video` →「无画面」
  - `seq` / `epoch` →「指令顺序不对（重连中）」
  - 提示只在这几秒内有新增丢帧时显示。

## 4. 回原点、中止并回原点

- **站点接口** `POST /api/robots/<id>/home/return {abort?: bool}`，权限 `dispatch`：
  - 这台机器人在当前地图上没有原点 → 409「当前地图上还没有原点：在原点位置点“设为原点”」。
  - 有任务在跑：
    - `abort` 不为真 → 409「正在执行任务，要先中止：用“中止并回原点”」；
    - `abort` 为真 → 先中止，等它进终态（最多 15 秒），再派。
  - 派一条 `goto` 到原点：优先级 `STANDBY_RETURN`，任务号前缀 `standby-`，这样自动回程的去重也认它。导航后端是 Nav2 就走 Nav2。
- **网页和手机**：两个按钮“回原点”“中止并回原点”。后者要二次确认，没任务在跑时不显示。

## 5. 路线页「派机器人跑一趟」

- 路线页每条路线加“派一趟”：先调已有的预计时间（`route_eta.estimate`），弹窗显示预计时长、派给哪台、现在要不要排队；确认后走现有的临时巡逻派单。
- 防区页顶部加一行提示：「防区只管报警；巡逻请到路线页派」。

## 6. 手机换图进度

- 代理在下载、校验、切换、加载定位各阶段发 `map_progress` 事件，带上阶段、已下载字节、总字节、失败原因。站点存最近一份，接口返回；手机显示：
  - 已下载多少 MB、按最近速度估算还要多久；
  - 校验、切换、定位加载各阶段；
  - 失败原因原文。

## 7. 开通码二维码用局域网地址

- 二维码和开通码里的站点地址，按站点主机的网卡列出局域网 IPv4，跳过回环、`docker*`、`br-*`、`veth*`。手动配置的 `--hostname` 照旧排在最前。
- 一个都没有时，页面上说清楚：「没找到局域网地址，请在站点设置里填对外地址」，而不是给 127.0.0.1。

## 8. 告警测试模式

- 管理员开启“告警测试模式”（带结束时刻，最长 2 小时）。期间产生的告警都打上 `test` 标记，照常推送，标题前加「测试」。
- “结束测试并清掉”一键把带标记的告警全部删掉（审计记一条，写明删了几条）；不带标记的不动。
- 到点自动结束，但不自动删。
