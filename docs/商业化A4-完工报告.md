# 商业化 A4 · 装机与开通 · 设计与完工报告

> 商业化 A 阶段（决策 53）。以前给一只狗开通，要在站点上 `enroll`，把五个文件拷进 U 盘，到狗上一个个放到位、改属主和权限，再手改 `/etc/d1max/env` 填站点地址。换个人就容易漏一步。

## 做了什么

### 一、开通码（站点）

- `d1max-site enroll <编号> --code`：签证书包的同时出一行**开通码**。给已经登记的狗重新出一个用 `d1max-site enroll-code <编号>`，旧码作废。
- 开通码是一行字：`D1MAX1.<base64url(JSON)>`，里面有：
  - 站点接口地址；
  - **站点服务证书的指纹**；
  - MQTT 地址；
  - 狗的编号；
  - 一个 24 字节的随机令牌。
- 开通码能贴、能发消息，以后手机上能显示成二维码。
- **一次性、24 小时有效**（`--hours` 可改）。站点只记令牌的哈希；同一只狗再出一个码，旧的作废。
- `POST /api/enroll/claim`：**不用登录**，令牌就是凭证。
  - 对得上、没用过、没过期、狗没吊销，才给证书包；
  - **给了就作废**：核对和作废在同一个事务里，两只狗拿同一个码，只有一只领得到；
  - 对不上一律回同一句话，不说是哪一样不对；
  - 记审计。

### 二、一条命令开通（狗）

`sudo /opt/d1max/bin/python -m d1max_patrol.cli provision --code '<开通码>'`：

1. 连站点接口，**先核站点服务证书的指纹**（钉住）。对不上就断开，令牌一个字节都不发，冒充的站点拿不到。
2. 拿令牌领证书包。
3. 放到 `/etc/d1max/`：
   - `tls/ca.crt`、`tls/robot.crt`；
   - `tls/robot.key`：**从写下去那一刻就是 0600**；
   - `registration.json`、`evidence-pub.key`；
   - 属主是代理的账号，代理要自己读私钥；先写临时文件再换名。
4. `/etc/d1max/env` 里填 `D1MAX_SITE_MQTT`，注释和别的行原样不动。
5. 打一遍出厂自检。

已经开通成**别的**编号的不换，一台狗只该有一个身份；确定要换加 `--force`。

### 三、出厂自检（狗）

`d1max-patrol selfcheck`，逐条打 PASS / WARN / FAIL，有 FAIL 时退出码 1：

| 检查 | FAIL / WARN 的时候 |
|---|---|
| 注册文件 | 读不了 → FAIL（还没开通？） |
| 三个证书文件 | 缺 → FAIL |
| 私钥权限 | 别的用户读得到、属主不是代理的账号 → FAIL |
| 发行公钥（含 `release-pub.d/`） | 没有 → WARN：站点下发的升级会被拒 |
| 证据公钥 | 没有 → WARN：照片、录像明文存 |
| `env` 的 `D1MAX_SITE_MQTT`、`D1MAX_MAP`、`D1MAX_HOME` | 没填 → FAIL：代理不起 |
| 连站点 | 用自己的证书跟站点 MQTT 做一次 TLS 握手，不通 → FAIL |
| 对时 | 没同步 → WARN |
| 盘 | 剩不到 15% → WARN |
| 代理服务 | 没在跑 → WARN（附上怎么起） |

装机清单（`docs/装机清单.md`）按这个改了：登记一步改成出开通码，「放证书包」改成一条开通命令，验收加上出厂自检。U 盘拷文件的老办法照样能用，没网的时候用。

## 测试

- **端到端**：
  - 真的 `init` 一个站点、登记一只狗、出开通码；
  - 用**站点自己的服务证书**起一个 HTTPS 服务；
  - 狗上真的跑开通：领到证书包，文件跟站点上签的一样，私钥 0600；
  - `env` 里只改了站点地址，注释、地图、适配器那几行都在；
  - 拿错的令牌开通，被拒。
- **钉指纹**：用另一个站点的证书冒充，开通失败，**冒充的站点一个令牌都没收到**。
- **开通码**：
  - 一次性，用过就作废；对不上一律同一句话；
  - 过期作废；重出一个，旧的作废；吊销了的狗不给。
- **命令行**：`enroll --code` 打出开通码；没登记的狗不给码。
- **接口**：领证书包不用登录，用过一次就 403；乱填的令牌也是 403。
- **换身份**：已经开通成别的编号的不换，`--force` 才换。
- **出厂自检**：
  - 缺什么说什么；
  - 私钥权限太宽 FAIL；
  - 都齐了全 PASS，没有证据公钥 WARN；
  - 连不上站点 FAIL，并带上原因。
- **测试抓到的两个真问题**：
  - 令牌按 ASCII 算哈希：别人乱填一串中文就让站点报 500，而不是正常拒掉。改成 UTF-8。
  - 领证书包的接口取时间时取错了对象，一调就 500。
- **突变**：8 条全抓住：不作废、不看过期、吊销了照给、不钉指纹、私钥权限太宽、换身份不拦、`env` 整个盖掉、自检不查私钥权限。

## 没做的

- **手机上扫码开通**：开通码已经是一行字，手机端显示二维码、狗上扫码要等 App V2（B 阶段）。狗上要扫码也得有相机读码的工具，现在是粘贴。
- **装机脚本自己不调开通**：装机和开通分开做，开通要站点在线；没网时还是走 U 盘的老办法。
- 开通码的接口没有按 IP 限速：令牌有 192 位随机数，猜不中；审计里有每一次领取。
