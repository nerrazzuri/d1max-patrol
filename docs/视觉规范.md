# D1 Max 视觉规范（B0）

> 2026-10-11 定：**A「夜巡」的深色配色 + C「工业」的布局，英文为主、中文可选**。**主战场是站点网页值班台**（保安电脑上整夜开着），手机是辅助。
>
> - 样稿：画布 https://claude.ai/artifact/2JqDNRH8tHNsYfoCEDTZgP 最下面一行「Final」，可点 EN / 中文 切换。
> - 数值的唯一来源：`design/tokens.json`。网页和 App 都从它取值，这份文档只讲怎么用。
> - `tests/test_design_tokens.py` 检查所有会叠在一起的颜色对，对比度要够 WCAG AA。
>
> Logo 还没有，先用「D1」字标占位；以后换 Logo 不影响下面任何规则。

## 一、原则

1. **夜里看得清、不刺眼。** 深色底，大面积用低亮度灰；亮色只给「需要人注意」的东西。
2. **颜色有意思才用。** 红 = P1 / 急停，琥珀 = P2 / 手动，绿 = 正常 / 布防，蓝 = 信息 / 充电。不拿颜色装饰。
3. **颜色从不单独说话。** 状态都配文字或图标（色弱、截图转黑白都读得出来）。
4. **数字和编号用等宽字。** 时间、电量、狗编号、距离用 IBM Plex Mono，一眼对齐。
5. **按英文排版、中文能放下。** 英文比中文长 1.5–2 倍：控件按英文的长度留位置，不截断、不缩字号。

## 三、字体与字号

- **英文**：IBM Plex Sans；**数字、编号、时间**：IBM Plex Mono。
- **中文**：Noto Sans SC（思源黑体）作回落，字重对齐（400 / 500 / 700）。

| token | 字号 / 行高 | 字重 | 用在 |
|---|---|---|---|
| `display` | 24 / 32 | 700 | 站点名 |
| `title` | 18 / 26 | 700 | 页标题、手机告警标题 |
| `heading` | 15 / 22 | 700 | 卡片标题 |
| `body` | 14 / 21 | 400 | 正文、按钮 |
| `label` | 13 / 18 | 600 | 徽标、状态、标签 |
| `caption` | 12 / 17 | 400 | 说明、时间线 |
| `overline` | 12 / 16 | 600，全大写，字距 0.06em | 分组小标题（中文不加字距、不大写） |
| `metric` | 30 / 34 | 600 等宽 | 电量、计数 |
| `clock` | 22 / 28 | 600 等宽 | 顶栏时钟 |

## 四、间距、圆角、尺寸

- **间距**：4 的倍数（`space`：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48）。卡片内边距 16，卡片之间 12，区块之间 16–20，页面边距 24。
- **圆角**：`sm` 6（徽标）、`md` 10（按钮）、`lg` 14（卡片）、`xl` 18（地图、浮卡）、`pill`（布防胶囊）。
- **点击区域**：至少 44×44。网页按钮高 40（鼠标），手机按钮高 52（手指）。
- **阴影**：只有浮在地图上的 P1 卡片有（`elevation.floating`），别的都靠底色分层。

## 五、布局

### 网页值班台（主界面）

```
┌──┬──────────────────────────────────────────────────────────┐
│D1│ DUTY CONSOLE · [Guard]          02:15:08 [EN|中文] [Disarm] [Stop all]
│  │ [Site name]  ● Armed                                      │
│▣ │ ┌──────────────────────────────────────────────────────┐ │
│⚠ │ │┌────────────┐                                         │ │
│▤ │ ││ P1 浮卡     │        实时地图（铺满）                  │ │
│◫ │ │└────────────┘                                         │ │
│▶ │ └──────────────────────────────────────────────────────┘ │
│▥ │ [D1-01 卡] [D1-02 卡] [D1-03 卡] [今晚 P2]               │
└──┴──────────────────────────────────────────────────────────┘
```

- **左侧图标栏**：80 宽，6 项：值班 / 告警 / 地图 / 狗 / 录像 / 报表。设置放在栏底或账号菜单里。图标在上、字在下，有未处理 P1 时「告警」上有红点。
- **顶栏**：
  - 左边是值班人和站点名；
  - 中间是布防状态胶囊；
  - 右边依次是时钟、语言切换、撤防、**全部急停**。全部急停固定在最右，红色实底，任何页面都在。
- **地图**：占满宽度，最少 500 高。**P1 浮卡固定在地图左上**，同时有多条 P1 时叠成一摞，显示「+2」。
- **下面一排卡片**：每只狗一张，最后一张是今晚的 P2。狗多于 4 只时这一排横向滚动。
- **窄屏**（< 1100）：卡片排成两列；< 720 时图标栏变成底部标签栏（同手机）。

### 手机

- 竖屏（App V2），390 宽设计。
- 告警详情的顺序：抓拍 → 地点和状态 → 四个大按钮（我来处理 / 升级 / 看实时画面 / 误报）→ 时间线。
- 底部标签栏 4 项：值班 / 地图 / 告警 / 我的。

## 六、组件

| 组件 | 样子 |
|---|---|
| **主按钮（危险）** | `p1` 实底 + 白字，`body` 700。用于「我来处理」「全部急停」 |
| **主按钮（正常）** | `accent` 实底 + `onAccent` 深字。用于「布防」「开始巡逻」 |
| **描边按钮** | 透明底 + `borderControl` 边 + `text` 字。在 P1 卡片里用 `p1Border` 边 + `p1Soft` 字 |
| **布防胶囊** | `accentBg` 底、`accent` 字和圆点，`pill` 圆角；撤防时 `surface` 底、`textMuted` 字 |
| **等级徽标** | P1：`p1` 实底白字；P2：`p2Bg` 底 `p2` 字。`label` 700，`sm` 圆角 |
| **P1 浮卡** | `p1Bg` 底、`p1Border` 边、红色顶条（等级 + 时间）、抓拍（标出检测框）、地点、状态、2×2 按钮 |
| **狗卡片** | `surface` 底：编号（等宽）+ 状态徽标、电量大数字、一行任务说明；离线时虚线边、整卡变灰 |
| **时间线** | 时间（等宽、`textMuted`）+ 事件；「下一步会发生什么」用 `p2` 色 |
| **抓拍检测框** | 2px `p1Text` 边，左上角标「Person 0.91」（等宽小字） |
| **语言切换** | 两段式分段按钮 `EN │ 中文`，选中的段 `borderStrong` 底 |

## 七、地图

| 元素 | 样子 |
|---|---|
| 场地边界 | `mapPlot` 底 + `borderStrong` 2px 边 |
| 建筑 | `surfaceRaised` 底 + `borderStrong` 边，名字用 `textMuted` |
| 巡逻路线 | `route` 2.5px 虚线（8 / 7） |
| 禁行区 | `noGo` 底 + `noGoBorder` 虚线边 + `noGoText` 字 |
| 狗 | 14px 圆，填状态色，3px 底色描边，下面是编号（等宽）；朝向是从圆心伸出的一条短线 |
| 告警点 | `p1Text` 实心点 + 40px 半透明红圈，**慢脉冲**（1.6 秒一次，系统设了「减少动态」就不动） |
| 摄像头 | 小三角扇形，`info` 色 |

## 八、图标

- 用 **Lucide**（ISC 许可，网页有 `lucide`，Flutter 有对应的包）：线宽 1.8、24 网格、圆角端点。
- 不用 emoji，不用填充式图标；同一屏的图标一个尺寸（图标栏 20，按钮 18）。

## 九、动效

- 只有两种：
  - 状态切换淡入，120–200 ms；
  - P1 告警点脉冲。
- 不做装饰性动画；系统设了「减少动态」就全部关掉。

## 十、中英文

1. **英文是默认语言**。第一次打开按浏览器 / 系统语言选：中文系统选中文，别的都选英文；用户选过就记住（网页按账号，手机按本机）。
2. **所有界面文字走词条**（key → en / zh），代码里不写死任何一种语言。缺中文词条显示英文，**不显示 key**。
3. **英文写法**：
   - 按钮用动词开头的 Sentence case（「Escalate to L2」，不写「ESCALATE」）；
   - 状态用形容词或分词（Armed、Offline、Charging）；
   - 不用缩写，除了 P1 / P2、L1 / L2。
4. **中文写法**：短、口语，跟现在 App 一致（「我来处理」「被撞了一下」）。
5. **不翻译的**：狗编号（D1-01）、地图上用户自己起的地名、人名。
6. **时间**：一律 24 小时制 `02:15:08`；日期英文 `11 Oct 2026`，中文 `2026-10-11`。**距离**：米（`6.2 m`）。**电量**：`78%`。
