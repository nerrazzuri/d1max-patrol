# 钥匙生成与保管（W57）

公司自己持有的钥匙有三把，各管一件事。客户站点自己的钥匙（站点 CA、备份、证据加密等）不在这里，由站点管理员按装机脚本的提示离线保存。

| 钥匙 | 文件 | 签什么 | 谁认它 |
|---|---|---|---|
| 发行签名钥匙 | `release.key`（私钥）、`release-pub.pem`（公钥） | 站点、机器人的升级包；App 的签名清单 | 站点、机器人（公钥随装机装上） |
| 解绑令钥匙 | `unbind.key`、`unbind-pub.pem` | 解绑令（让一台机器人清机、解除绑定） | 机器人（公钥出厂烧写时装进去；换钥匙时随发行加新的） |
| 安卓签名钥匙 | `android-release.jks`（别名 `warden`，带密码） | 安卓 App 安装包 | 安卓系统（只接受同一把钥匙签的新版本） |

## 一、生成（只做一次，你本人做）

**现阶段（用户 2026-10-31 定）：三把钥匙先放在台式机上**，目录 `~/nexus-keys`（仓库外面，只有你的账号能读）。
正式发行前挪到两个加密 U 盘（一主一备），台式机上的删掉。下面命令里的目录按现阶段写。

1. 在台式机的仓库目录里运行（安卓那一步会问两次密码）：
   ```bash
   .venv/bin/python tools/make_keys.py --out ~/nexus-keys --org "<公司名>"
   ```
   keytool 会问两次密码：这是安卓签名钥匙的密码，**写在纸质保管记录上**，跟 U 盘分开放。
3. 看 `nexus-keys/钥匙说明.txt`，按里面的「下一步」做：
   - 把 `release-pub.pem` 复制到仓库的 `deploy/release-pub.pem`，提交（走 PR）；
   - 出厂烧写机器人时用 `unbind-pub.pem`（`factory burn --unbind-pub`）；
   - 发行机上的 `mobile/android/key.properties` 指向 `android-release.jks`（见 `docs/正式发行手册.md`）。
4. 现阶段至少拷一份到 U 盘或移动硬盘做备份（台式机硬盘坏了钥匙就没了）。正式发行前：拷到两个加密 U 盘，两份分开放（比如一份随身、一份保险柜），删掉台式机上的。

## 二、保管规矩

- 现阶段私钥在台式机 `~/nexus-keys`（目录权限 700，文件 600）加一份离线备份；正式发行前改为只在两个加密 U 盘上。
- **不放 GitHub、网盘、聊天软件、邮箱**；不放进仓库目录（脚本会拒绝）。
- 只有你能签（发行、解绑令）。别人要用，你来签。
- 保管记录（纸质）：生成日期、钥匙编号（`钥匙说明.txt` 里有）、安卓密码、两个 U 盘各放在哪。

## 三、平时怎么用

- **发行**：按 `docs/正式发行手册.md` 第三节跑 `tools/make_release.py --key ~/nexus-keys/release.key …`（改用 U 盘后换成 U 盘上的路径）。
- **签解绑令**：按 `docs/解绑令签发流程.md`。
- 改用 U 盘后：用完拔掉。

## 四、丢了或怀疑泄露

| 钥匙 | 丢了（两份都没了） | 怀疑泄露 |
|---|---|---|
| 发行签名钥匙 | 生成新的；新公钥放进 `deploy/release-pub.d/`，**每个站点、每台机器人要人到现场装一次新公钥**（旧钥匙签不了，带不过去）。见 `docs/商业化A3-完工报告.md` 的轮换流程 | 立刻生成新的；先用旧钥匙签一版只带新公钥的包发下去，再下一版起用新钥匙签，最后把旧公钥从仓库删掉 |
| 解绑令钥匙 | 生成新的；新公钥放进仓库 `deploy/unbind-pub.d/<日期>.pem`，**随下一次发行装进每台机器人**，之后就能用新钥匙签 | 同上，并把旧钥匙编号写进 `deploy/unbind-revoked.txt`（一行一个，`#` 开头写原因），随发行生效：机器人不再认旧钥匙签的解绑令（出厂那把也能这样作废） |
| 安卓签名钥匙 | 没法补救：客户手机上的 App 只能卸载重装（设置会丢）。所以备份一定要有 | 生成新的，同上；通知客户卸载重装 |

单独补安卓签名钥匙（脚本里 keytool 那一步没成时）：

```bash
keytool -genkeypair -keystore ~/nexus-keys/android-release.jks -alias warden \
  -keyalg RSA -keysize 4096 -validity 10000 -dname "CN=Nexus Warden, O=<公司名>"
```
