# W00c6g 建图进程日志 · 完工报告（供审核）

> 来源：W00c5e 退役的老服务 `GET /api/procs/<name>/log`（子进程日志的尾巴）；决策 9，P1。设计决定按推荐取。

日期：2026-09-26 · 规模 S · 设计：`docs/superpowers/specs/2026-09-26-W00c6g-proc-logs-design.md`

## 问题

录包、重建（W00c5d 第二部分）在狗上起子进程（ROS 录包、隔离域里 slam_toolbox 离线重建、存图），每个进程的输出落在狗上的日志文件里
（`ProcManager` 的日志目录，一个进程一个 `<名字>.log`）。老服务能在页面上看这些日志的尾巴；W00c5e 删了老服务，录包、重建失败时站点
只收到一句「退出码 N，日志见 ……」，要看原因只能 SSH 上狗。

## 交付

| 层 | 改了什么 | 文件 |
|---|---|---|
| 代理 | 新命令 `proc_log`（不是任务，只读）：`{}` → 回执 `data` 是日志列表 `{logs: [{name, size, mtime_ms}]}`（按修改时间倒序，最多 50 个）；`{name, bytes?}` → 那个日志的尾巴 `{name, size, bytes, truncated, text}`，默认 64 KiB、最多 128 KiB，从行首截、坏字节替换，**按 JSON 编码之后的大小再裁到 160 KiB 以内**。名字只许 `[a-z0-9_.-]{1,48}`，只在日志目录里找，**链接当没有**；没有这个日志 `no_such_log`；读失败 `read_failed`。读文件在线程里做。**不进幂等记录**（`READ_KINDS`）。狗有录包能力（有日志目录）才报这项能力 | `proc_logs.py`（新）、`runtime.py`、`commands.py`、`mapping.py`；根包 `app/procs.py`、`app/mapping.py`（`log_dir` 一路报上来） |
| 站点 | `GET /api/robots/<id>/logs`（列）、`GET /api/robots/<id>/logs/<name>?bytes=`（尾巴），**管理员**。名字、`bytes` 不像话 400；狗说没有 404、别的拒 409、老代理 409；回执里的数据原样给。**这条回执不推给事件流（SSE）**（`_QUIET_KINDS`） | `api.py`、`dispatcher.py` |
| 手机 | 单狗页给管理员「建图日志」（狗报了 `proc_log` 才有）→ 列表（名字、大小、时间）→ 点开看尾巴（等宽字、能选、能滚；前面还有没给的说「只显示最后 …」）；两页都有刷新；没有日志、取不到说清楚。横屏不溢出 | `ui/site_logs.dart`（新）、`ui/site_page.dart`、`net/site_client.dart` |

## 与设计稿不同的地方

实现时发现、设计稿已跟着改（标了「实现时改的 / 加的」）：

1. **尾巴最多 128 KiB（设计写 256 KiB），而且按编码之后的大小再裁。** 回执走 MQTT，站点 broker 单包上限就是 256 KB
   （`broker_conf.py` 的 `max_packet_size 262144`）—— 超了 broker 会把狗断开。带颜色的日志里控制字符（`ESC`）在 JSON 里一个字节
   变六个（`\u001b`），128 KiB 也可能胀过线，所以裁到编码后 160 KiB 以内。
2. **不进幂等记录。** 地图、发布命令的回执都记进幂等记录（连同 `data`），代理起来全量重放；一条日志尾巴就上百 KB。只读查询重投
   再查一次就是，同 `video`、续租。
3. **查日志的回执不推给事件流。** 站点把每条回执推给事件流，谁登录了都收得到（保安、业主也是）；日志只给管理员（设计决定 2）。
   而且手机收到事件流的每一帧都会刷新狗的列表，只读查询不该让所有人跟着刷（W00c6h 的录包轨迹每 2 s 查一次，同样处理）。

## 已知限制

- 只给尾巴、不实时跟（设计的「不做」）；代理自己的日志（journald）不在这一单。
- 128 KiB 的尾巴是一次命令、一个回执；4G 下慢，但比 SSH 快。要看更前面的只能上狗。
- 站点每查一次在 `commands` 表里记一行（跟别的命令一样），不记日志内容。
- 真机没验：真狗上录包、重建之后看日志（3c.23 之后）。

## 测试与突变

- **测试**（先红后绿）：
  - 代理（`packages/robot-agent/tests/test_proc_log.py`，真代理 + 仿真狗 + 假录包服务）：列日志倒序、只列日志目录里的 `.log`；尾巴
    默认、指定、上限、从行首截、坏字节替换、短文件不截；满是控制字符的日志回执编码后不到 200 KB；名字不像话、穿越拒；没有这个日志、
    `bytes` 不像话拒；链接当没有（列表里也不列）；不进幂等记录、重投再查一次；没有录包能力不报；日志目录从进程管理器经编排报到录包服务。
    根包 `tests/agent_tools/test_mapping.py`：编排照进程管理器报日志目录。
  - 站点（`test_site_proc_log.py`）：管理员列、取尾巴（`bytes` 进命令），保安 403；名字、`bytes` 不像话 400；狗说没有 404、别的拒 409；
    老代理 409；**真代理端到端**：列表、尾巴、没有的 404，事件流里没有这条回执、也没有日志内容，别的回执照推。
  - 手机（`site_logs_test.dart`）：管理员单狗页 → 列表 → 尾巴 → 两页刷新；保安、狗不支持没有入口；没有日志、取不到说清楚；大小说人话。
    `site_client_test.dart`：请求形状（名字编码、`bytes` 放查询串）。`landscape_test.dart`：两页横屏不溢出。
- **突变 32 条（Python 23、手机 9），杀 30 条，2 条等价**。第一轮活 6 条：列表最多 50 个没测（补 55 个日志）；尾巴 128 KiB 的封顶被「按编码裁」兜住了（测试的日志 190 KB，编码后过线被砍半，封顶去掉也过）—— 补一条普通 150 KiB 的日志只给最后 128 KiB；站点 `bytes=0`、负数没测（补上）。等价的两条：列表 `glob("*.log")` 换成 `glob("*")`（每个名字还要按 `<名字>.log` 再核一遍是不是真文件，别的文件本来就列不出来）；手机不给日志名做 URL 编码（名字只能是 `[a-z0-9_.-]`，编不编码一样）。
